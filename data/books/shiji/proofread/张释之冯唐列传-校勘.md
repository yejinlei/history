# 张释之冯唐列传第四十二 校勘记

> 本记只列异文、通假、异体、古今字及疑似讹脱，**不改底本一字**。底本用字一律保留（繁体），白话译文行用规范简体。

## 一、通假字

| 段 | 底本 | 通 | 说明 |
|----|------|----|------|
| p0 | 以訾爲騎郎 | 訾＝资 | 「訾」通「资」，家财。汉制家资五百万以上得选为郎。 |
| p4 | 雖錮南山猶有郄 | 郄＝隙 | 「郄」通「隙」，缝隙、孔隙。 |
| p4 | 居北臨厠 | 厠＝侧 | 「厠」一说通「侧」，边侧。 |
| p1 | 豈斆此嗇夫 | 斆＝效 | 「斆」通「效」，效法、像。 |
| p1 | 諜諜利口捷給 | 諜諜＝喋喋 | 「諜諜」通「喋喋」，多言貌。 |
| p4 | 蕠漆其閒 | 蕠＝濡（一说） | 「蕠」通「濡」，黏、胶合，谓以漆胶合填塞。 |
| p5 | 民安所錯其手足 | 錯＝措 | 「錯」通「措」，安放。 |
| p6 | 坐前玉環 | 坐＝座 | 「坐」通「座」，神座。 |
| p6 | 非吾所以共承宗廟意也 | 共＝恭 | 「共」通「恭」，恭敬。 |
| p11 | 殺北地都尉昂 | 昂＝卬 | 「昂」通「卬」，北地都尉孙卬。 |
| p11 | 爲秦所禽滅 | 禽＝擒 | 「禽」通「擒」，擒获。 |
| p11 | 上功莫府 | 莫＝幕 | 「莫府」通「幕府」，将帅官署。 |
| p11 | 有兄仲同居 | — | 「仲」为张释之兄之名（字仲），非行次之泛称。 |

## 三、异文、疑似讹脱

| 段 | 底本 | 异文/他本 | 说明 |
|----|------|-----------|------|
| p11 | 尺籍五符 | 尺籍伍符 | 「五符」或作「伍符」，军中编制符信；两说并存，底本作「五符」。 |
| p11 | 滅澹林 | 襜襤（一作） | 澹林为北方部族名，一作「襜襤」，字异实同。 |
| p11 | 爲官卒將 | 官帥將（一作） | 「官卒將」一作「官帅将」，军中官名，存疑。 |
| p0 | 久宦減仲之產 | — | 底本「減」谓减耗，指做官耗损兄产。 |
| p4 | 用紵絮斮陳 | — | 「斮陳」谓切碎铺陈；一说「斮陳」为「错陈」之讹，存疑。 |
| p12 | 七年，景帝立 | — | 「七年」指文帝后元七年（前157年），文帝崩、景帝即位之年。 |
| p13 | 不偏不黨，王道蕩蕩 | 《尚书·洪范》 | 引《书》，文字与今传《洪范》略异，底本照录。 |
| p14 | 索隱述贊 | — | 司马贞《索隐》述赞，非司马迁原文，依体例保留原文＋语词典释。 |

## 四、校勘结论

- 底本用字与今体差异，主要为通假与异体，**不影响文义**者从底本照录；
- 「尺籍五符」「官卒将」「澹林」「斮陈」四处属异文或存疑，已出校说明，未改底本；
- 白话译文行统一用规范简体，人名地名从今通行写法（张释之、冯唐、廉颇、李牧、魏尚等）。
