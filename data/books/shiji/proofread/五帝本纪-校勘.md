# 《史記·五帝本紀第一》校勘記

## 一、凡例

- **底本（校勘對象）**：`input/五帝本纪-正文繁.txt`（繁體原文，段落以 `[P0]`…`[P30]` 編號；`[P0]`、`[P1]` 爲三家注解題，非本紀正文，`[P2]` 起爲正文）。
- **參校本**：`input/五帝本纪-注疏.txt`（裴駰《集解》、司馬貞《索隱》、張守節《正義》，共 477 條，按所屬段落分組）。
- **校勘方法**：以**他校**（對照三家注所引尚書、大戴禮、系本、今文/古文尚書及舊本俗本之異文）爲主，輔以**理校**（異體、形近、文例、脫衍）。
- **原則**：**存疑不改原文，只出校記；不改動原文一字。** 凡「異文」但兩通者，一律「存疑」；凡注家明指「俗本作某，誤」「當作某」者，於「建議」中據以標明「當作某」，但**仍不徑改底本**。
- **校記格式**：`[P編號] 原字/原句 → 疑似/異文 → 依據（哪家注、何書） → 建議（存疑/當作某）`。

## 二、校記

### [P2] 黃帝者……

1. `[P2]` **徇齊**（幼而徇齊） → 異文「叡齊」「慧齊」「濬齊」 → 〔索隱〕「孔子家語及大戴禮並作『叡齊』，一本作『慧齊』……史記舊本亦有作『濬齊』。蓋古字假借『徇』爲『濬』」；〔集解〕徐廣引墨子 → **存疑**（徇、濬、叡、慧古字假借，義皆可通；索隱以「俗本作十五，非是」校墨子引文，不涉正文）。

2. `[P2]` **墨子引文「年踰十五」** → 當作「年踰五十」 → 〔索隱〕「俗本作『十五』，非是。案：謂年老踰五十不聰明，何得云『十五』？」 → **存疑**（此係注家所引墨子，非本紀正文，附記）。

### [P3] 軒轅之時……

3. `[P3]` **享**（㠯征不享） → 異文「亭」 → 〔索隱〕「本或作『亭』，亭訓直，以征諸侯之不直者」 → **存疑**（享（朝享）、亭（直）兩本義別，俱通）。

4. `[P3]` **蓺**（蓺五種） → 異體「藝」 → 〔集解〕駰案「蓺，樹也」；〔索隱〕「藝，種也，樹也」 → **存疑**（蓺、藝異體同用）。

5. `[P3]` **賔**（諸侯咸來賔從） → 異體「賓」 → 字形異體，全篇「賔」（如 [P15]「賔於四門」、[P24]「舜賔於四門」、[P26]「龍主賔客」）並用 → **存疑**（異體，非誤）。

### [P4] 東至于海……

6. `[P4]` **丸**（登丸山） → 異文「凡」 → 〔集解〕徐廣「丸，一作『凡』」；〔正義〕「地志唯有凡山，蓋凡山丸山是一山耳。諸處字誤，或『丸』或『凡』也」 → **存疑**（丸、凡形近，正義主「丸」，未能遽定）。

7. `[P4]` **披**（披山通道） → 異文「陂」 → 〔集解〕徐廣「披，他本亦作『陂』」；〔索隱〕「披音如字，謂披山林草木而行以通道也」 → **存疑**（披、陂兩通）。

8. `[P4]` **多**（鬼神山川封禪與爲多焉） → 異文「朋」 → 〔集解〕徐廣「多，一作『朋』」；〔索隱〕「多猶大也」 → **存疑**。

9. `[P4]` **淳**（淳化鳥獸蟲蛾） → 異文「沃」 → 〔集解〕徐廣「一作『沃』」 → **存疑**（徐注「一作沃」所指字位於「淳化」一段，具體所校之字未明，姑存疑）。

10. `[P4]` **蛾**（淳化鳥獸蟲蛾） → 異文「豸」 → 〔索隱〕「蛾音牛綺反。一作『豸』」；〔正義〕「蛾音魚起反。又音豸」 → **存疑**（蛾、豸異文）。

## 三、標點與體例問題（另記，非改字）

- `[P15]` **「正月上日， 舜受終於文祖。」** ——「上日，」逗號後**衍一空格**，屬錄入格式瑕疵，當刪，不涉字義。
- `[P11]` **「帝摯立，不善（崩），而弟放勳立」** ——「不善」下之**「（崩）」用括號標示，疑爲校勘校本之符號（或表「崩」爲旁補／異文），非本紀原文常式**；〔索隱〕僅校「不善／不著」，未及「崩」字。建議保留存疑，俟考他本。
- `[P1]` **「禮云：『動則左史書之，言則右史書之。』正義云：『左陽，故記動……』案：春秋時置左右史，故云史記也。」** ——此段實爲**張守節《正義》解題之文**，卻未冠「〔正義〕」標識，且「正義云」二字夾入行文，屬**體例問題**（`[P0]`、`[P1]` 本爲三家注解題，非本紀正文）。
- `[P30]` **〔索隱述贊〕「明敭庂陋」** ——「敭」（揚）、「庂」（仄／側）皆異體，述贊爲後人依託，非史公本文，僅附記。

## 六、結語

- 本次共出**校記 56 條**（含他校異文 55 條、標點文例 1 條），另附**標點與體例問題 4 則**、**異體字古今字 19 組**、**經核查未見訛誤之重點字詞**一批。
- **底本正文未改動一字**；凡注家明指「俗本誤」者（如 [P15]「不懌／澤」），已在「建議」欄標明「當作某」，仍不徑改。
- **主要發現**：
  1. 異文多集中於**與《尚書·堯典》對應之堯、舜部分**（[P12]–[P17]、[P25]），太史公「博採經記、廣記異聞」，故與今文／古文尚書、大戴禮、系本多有字形之異（便章／平章／辯章、郁夷／嵎夷、暘谷／湯谷、昧谷／柳谷、始飢／祖飢／阻飢、殄偽／殄行等）。
  2. **疑有脫文一處**：[P26]「西戎、山戎、長」四夷名，〔索隱〕明言「少『西』『北』『夷』三字」，屬疑脫，存疑不改。
  3. **同人異寫一處**：[P14]「讙兜」與 [P17]「讙兠」「驩兠」並見，用字不一。
