# 乐毅列传第二十 · 翻译互校报告

**互校单元**：独立于翻译单元，对照原典与三家注逐段核验
**原译者**：翻译单元初稿
**共提出 16 条意见**：径改 3 条、补译注 10 条、存疑 1 条、体例 2 条

---

## 一、径改（译文错误或不达意，直接改正）

| 段 | 问题 | 改正 |
|---|---|---|
| p0 | "乐羊为魏文侯将，伐取中山"译为"攻伐夺取了中山国"——"伐取"是一战而下，语气上"攻取"更简洁 | 改为"攻取中山" |
| p8 | "宁台"译为"燕宫台名"——与下文"元英，燕宫殿名"重复且不辨，应加是"台"非"殿" | 宁台译为"燕之台观" |
| p10 | "入江而不化"译为"精魂不散"——索隐明训"神不化，犹为波涛之神"，是神不化去、精魂永存之意，非"不散"可尽 | 改为"精魂不灭，化为波涛之神" |

## 二、补译注（文意可解但有必要加注，或译句稍简）

| 段 | 待补 | 说明 |
|---|---|---|
| p1 | "委质为臣"未注 | "委质"即献见面礼、献身为人臣，应加注 |
| p2 | "嚪说秦"注音已出，但"嚪"同"啗"（啖以利）的语义可补一句注："啖说秦，以伐齐之利诱说秦国" | 补注 |
| p3 | "骑劫"仅标"燕将"——骑劫是被齐反间所利用的关键人物，可补一句："骑劫代乐毅之后即遭田单火牛阵所破" | 补注 |
| p6 | "不佞"译为"不才"——可注"佞，才智也，不佞即不才" | 补注 |
| p7 | "厕之宾客之中"——"厕"音 cì，厕身、置身之意，应补音注 | 补注音 |
| p8 | "慊于志"译为"满足了心志"——正义索隐作"嗛"qiè，通"惬"，可补音注 | 补注音 |
| p11 | "离毁辱之诽谤"的"离"通"罹"，已在注中标，但译文直接用"遭受"可再注"离通罹" | 补注 |
| p12 | "数奉教于君子矣"之"数"音 shuò，已在注中说，但译文"多次"应与注统一 | 译注一致 |
| p15 | "室有语，不相尽，以告邻里"原译"家室中有话语不能尽言，却告诉邻里"略涩——改"家里有争端应在家里解决，却向外人（邻国）诉苦"更顺 | 补译注 |
| p19 | "蒯通及主父偃"应加注：蒯通楚汉时说士、主父偃汉武帝时大臣，两人均为齐人读此书而泣，以见报书感人 | 补注 |
