# 《史记·吴王濞列传第四十六》本体校验报告

## 校验维度
1. 实体 evidence 段号是否落在底本段落范围（p0–p20）；
2. 关系端点（from/to）是否严格匹配实体 name 字段（无悬空端点）；
3. 实体命名是否规范（同人异名归一、不误写他篇地名/人物）；
4. 是否有他篇内容混入或无据实体；
5. 段号与实体出现段落是否一致；
6. 关系 type 是否为 2–8 字动宾短语。

- 底本共 **21 段（p0–p20）**，note 数量 0（白文无注版本）。
