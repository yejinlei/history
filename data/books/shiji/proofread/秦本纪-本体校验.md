1. **同名君主核验（通过）**：两位「惠公」（哀公之孙 `huigong`／简公之子 `huigong2`）与两位「出子」（宁公之子 `chuzi`／惠公之子 `chuzi2`）在初稿中已按 id 正确分列，世系、谥号、事迹均未错配，唯命名同形易混，故仅列第22条（描述错）提示消歧，不计为错配。另，正文另见「齊悼公（陽生）」「晉襄公」等同名异人，初稿未纳入，可视体例补。

2. **evidence 覆盖不完整（未计为错）**：
   - `shiji-person-elai`、`shiji-person-feilian` 之别名「恶来革」「飞廉」等，与 description 所引注疏（正义、索隐）路径，可补列。
   - `shiji-office-daliangzao` evidence 仅 [P54,P65]，漏 P60「陰晉人犀首爲大良造」。
   - `shiji-person-chenggong` evidence [P14,P15,P16] 未含 P13（第14行「中子成公」首见）。
   - `shiji-person-rongwang`、`shiji-person-youyu` 之 P32/P34 覆盖无误，惟由余主事段（第33行）与他段界限可再核。
   以上属「可补可不补」，除已列条目外未改动。

3. **id/命名**：`shiji-person-jinggong`（竫公）与 `shiji-person-jinggong2`（景公）音近不同字，id 已靠后缀区分，可接受。`shiji-person-xianggong`（襄公）与 `shiji-person-xiangong`（献公）仅差一字母，建议后续统一体例（如 `xiang-gong`/`xian-gong`）以免误引，本期未改名。

4. **关系可商（未计）**：`shiji-event-ninggong-qianpingyang` participants 含 `wugong`（武公），武公乃宁公之子、后嗣，非徙居平阳之主事者，端点略宽，可保留；`shiji-event-degong-juyong` evidence 含 P12（仅「立其弟德公」），初居雍城实见 P13，属边界情形。均未改动。

5. **校验通过项**：全部 evidence 段落号均在 P0—P70 范围内（正文 73 行，第72、73行为「太史公曰」「索隱述贊」，无实体）；149 个实体 id 无重复、前缀规范；relations 端点均指向已登记实体；注疏〔pN〕与正文 P 编号一致（〔p4〕〔p22〕〔p30〕〔p36〕〔p40〕〔p47〕〔p67〕等缺失系对应段无注，非错）。
