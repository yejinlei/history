# 夏本纪第二·本体校验

本体校验针对《史记·夏本纪》本身的内容可信度、世系完整性、地理一致性、制度合理性进行，以传世文献和考古成果为参照，校验范围包括夏代世系、重大事件、地理体系、制度记载四个方面。

## 一、夏代世系完整性校验
1. **《夏本纪》所载世系**：禹→启→太康→中康→相→少康→予（杼）→槐（芬）→芒（荒）→泄→不降→扃→厪（胤甲）→孔甲→皋→发→履癸（桀），共14世17君，世系清晰。
2. **异本对照**：
   - 《世本》记载夏世系与《史记》基本一致，仅个别君主名有通假异文；
   - 《竹书纪年》记载的夏世系除加上「羿、寒浞」篡位的无王时期（约40年）外，君主顺序与《史记》一致，没有缺失；
   - 《帝王世纪》的夏世系也与《史记》大体吻合，仅在位年数有差异；
   - 近出遂公盨铭文记载「天命禹敷土，随山浚川」，证明西周中期大禹治水的传说已经广泛流传，和《禹贡》《夏本纪》的记载吻合。
3. **校验结论**：《夏本纪》记载的夏代世系是现存最完整的夏王世系，和多种先秦文献可以互证，没有重大缺环，基本可信。但世系中存在兄终弟及（太康-中康、不降-扃），符合早期国家继承制度的特点。
4. **待说明点**：《史记》没有记载「后羿代夏」「寒浞杀相」的失国时期，从「太康失国」直接到「中康立」「相立」「少康立」，略去了约四十年的无王阶段，这是因为司马迁采用的是儒家「一以贯之」的正统世系书写，不把篡位者算入正统，属于史书体例，不是世系缺失，司马贞索隐述赞补充了这段历史，今在校勘记中说明。

## 二、重大事件一致性校验
1. **大禹治水**：
   - 《尚书·禹贡》《诗经》《论语》《孟子》《左传》《国语》《墨子》等大量先秦文献都记载大禹治水事迹，内容基本一致：禹继父业、疏九河、定九州、过家门不入，最终治水成功；
   - 考古发现：新石器时代晚期（龙山文化末期，约前2000年左右）黄河流域确实发生过大规模洪水，河南新砦遗址、二里头遗址都有洪水沉积的证据，和文献记载的大禹治水时间吻合；
   - 校验结论：上古大洪水的史实有考古证据支撑，大禹治水的传说流传广泛、记载一致，基本史实可信，具体细节（如九年/十三年治水、三过家门不入）带有传说成分，但核心事件存在。
2. **禹启世袭、家天下开始**：
   - 《战国策·燕策》说「禹名传天下于益，已而实令启自取之」，和《夏本纪》「益佐禹日浅，天下属意启」「诸侯去益而朝启」的记载一致；
   - 《竹书纪年》说「益干启位，启杀之」，和《史记》「益让启」的说法不同，是战国不同学派的记载差异，《史记》采用的是儒家禅让让贤的说法，《竹书纪年》采用的是权力争夺说法；
   - 有扈氏不服，启伐有扈氏，大战于甘，作《甘誓》，《尚书·甘誓》即此事件的原始文献，和《史记》记载完全一致；
   - 校验结论：启继禹位是禅让制向世袭制转变的关键事件，甘之战是真实历史事件，启建立夏朝、家天下开始的史实可信，具体权力交接的过程存在不同文献记载差异。
3. **太康失国、少康中兴**：
   - 《左传》襄公四年、哀公元年详细记载了后羿代夏、寒浞杀羿、杀帝相、少康奔有虞、复国灭浞的完整过程，和《夏本纪》「太康失国」「少康立」的简略记载吻合；
   - 《楚辞·离骚》《天问》也提到后羿、寒浞、少康复国的事迹，记载一致；
   - 校验结论：太康失国、少康中兴是夏代早期的重大事件，《左传》等文献记载详细，史实可信，《史记》记载简略但主线正确。
4. **孔甲乱夏**：
   - 《国语·周语下》说「孔甲乱夏，四世而陨」，和《夏本纪》「孔甲立，好方鬼神，事淫乱。夏后氏德衰，诸侯畔之」的记载完全一致；
   - 刘累豢龙的故事出自《左传》昭公二十九年，《史记》照录，属于上古传说，反映了孔甲时期夏与陶唐氏、豕韦氏等部族的关系；
   - 校验结论：孔甲是夏朝由盛转衰的关键君主，「孔甲乱夏」是传世文献的一致记载，史实可信，豢龙传说属于神话化的历史记忆。
5. **夏桀暴政、鸣条之战夏亡**：
   - 《尚书·汤誓》是商汤伐桀的誓师词，记载夏桀暴政「夏王率遏众力，率割夏邑」，和《史记》「桀不务德而武伤百姓，百姓弗堪」一致；
   - 《诗经·商颂·长发》「韦顾既伐，昆吾夏桀」记载了商汤伐夏的顺序：先灭韦、顾、昆吾，最后伐桀；
   - 鸣条之战桀败走、被流放，《孟子》《国语》《竹书纪年》都有记载，一致；
   - 二里头文化在第四期（约前1600年）被商文化（二里岗文化）取代，时间和夏商分界吻合，地点和夏晚期都城斟寻（河南偃师二里头遗址）吻合；
   - 校验结论：夏桀亡国、鸣条之战是信史，和考古发现吻合，夏朝灭亡的时间约为公元前1600年，和夏商周断代工程结论一致。

## 三、地理体系一致性校验
1. **九州体系**：
   - 《夏本纪》的九州完全照录《尚书·禹贡》九州：冀、兖、青、徐、扬、荆、豫、梁、雍，各州的山川、土壤、贡赋、贡道都和《禹贡》一致，没有差异；
   - 校验结论：《禹贡》九州是战国时期形成的地理概念，不是夏朝实际的行政区划，但司马迁作为史料完整采用，地理名称的记载保留了先秦地理知识，有重要史料价值。
2. **五服制度**：
   - 五服（甸、侯、绥、要、荒）同样来自《禹贡》，是先秦学者的理想化政治地理模型，不是夏朝实际实行的制度；
   - 校验结论：五服制度是后世对上古服制的理想化设计，反映了早期国家「中心-边缘」的天下观，但不是夏朝的实际制度。
3. **夏代都邑地望**：
   - 禹都阳城：今河南登封王城岗遗址，发现有龙山文化晚期大城（约30万平方米），年代约前2100年，和禹都阳城的时间、地点吻合；
   - 夏启都阳翟：今河南禹州瓦店遗址，是龙山文化晚期大型遗址，和阳翟地望吻合；
   - 太康、羿、桀都斟寻：今河南偃师二里头遗址，面积约3平方公里，是夏代晚期都城遗址，年代约前1750-前1500年，和斟寻地望吻合；
   - 夏桀囚汤于夏台：夏台在今河南禹州，距二里头遗址不远，符合地理位置；
   - 鸣条：今山西运城安邑，在夏都斟寻的西北，商汤从东方（商丘一带）西进，桀败退到鸣条，战败后南逃南巢，地理路线合理；
   - 校验结论：《夏本纪》记载的夏代都邑地望大多有考古遗址对应，地理路线合理，没有大的地理矛盾。
4. **山川名称**：
   - 九山、九川的名称大多是先秦时期真实存在的山川，只是由于河道变迁，部分古水（如济水、漯水、沇水）今天已经消失或改道，但在《水经注》等文献中都有迹可循；
   - 校验结论：山川名称符合先秦地理实际，没有虚构地名。

## 四、制度记载合理性校验
1. **贡赋制度**：
   - 「众土交正，致慎财赋，咸则三壤成赋」，即按土壤等级定赋税，符合早期国家贡赋制度的特点；
   - 「禹会诸侯于涂山，执玉帛者万国」「禹会诸侯江南，计功而崩，命曰会稽」，说明禹时期已经有诸侯朝贡、会盟制度，是早期国家形成的标志；
   - 校验结论：贡赋制度的记载符合早期国家的特点，九州贡赋的具体规定是《禹贡》的内容，带有理想化色彩，但贡赋制度本身在夏代已经出现。
2. **官制**：
   - 司空（掌工程水利）、士（掌刑法）、稷（掌农业）、司徒（掌教化，契为司徒）、四岳（方伯）等官职，符合上古官制的特点；
   - 六卿、六师等军事制度，和夏代早期国家的军事制度吻合；
   - 校验结论：官制记载基本符合夏代国家形态，没有明显的后世制度附会。
3. **礼制**：
   - 「祖」「社」祭祀：赏于祖、戮于社，是先秦时期的礼制，祖庙祭祀祖先、社坛祭祀土地神，符合三代礼制；
   - 玄圭赏赐：舜赐禹玄圭，是上古时期锡命制度的反映，圭是贵族身份和权力的象征；
   - 箫韶九成：韶乐是舜时的乐舞，孔子称其「尽善尽美」，符合先秦礼乐记载；
   - 校验结论：礼制记载符合先秦礼乐制度，真实性较高。
4. **历法**：
   - 「孔子正夏时，学者多传《夏小正》」，《夏小正》是现存最早的农事历，保存了夏代的历法知识，以建寅为正（正月为岁首），符合夏历的特点，今天的农历又称「夏历」，即源于此；
   - 中康时羲、和「废时乱日」被胤征讨，说明夏代已经重视历法，历法是国家重要的政事，符合早期农业社会的特点；
   - 校验结论：历法记载可信，《夏小正》确实保存了夏代历法知识。

## 五、本体校验结论
1. 整体而言，《史记·夏本纪》的记载体系完整、世系清晰、地理合理、制度符合早期国家特点，和大量先秦文献可以互证，并且得到越来越多考古发现的支撑，核心史实是可信的。
2. 其中的九州、五服等内容来自《尚书·禹贡》，是战国学者对上古制度的理想化建构，不是夏朝实际的行政区划和制度，但作为先秦史料有重要价值。
3. 部分上古传说（如黄帝世系、玄鸟生商、神龙、凤凰等）是上古神话历史化的产物，反映了上古时期的历史记忆，不能完全作为信史，但也并非完全虚构，保留了早期历史的影子。
4. 《史记》对夏朝历史的记载是现存最早、最系统的夏史记载，虽然存在简略、略去失国时期等问题，但整体可靠性较高，是研究夏史的核心文献。
