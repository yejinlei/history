## 总体结论

初稿共收录实体 **126 条**（人物 87、地理 15、事件 15、概念 9）。从体量看，本篇横跨西周初至秦二世约八百年、记卫国四十余君，人物密度大、外涉齐晋楚周郑陈蔡等多国，**126 条与原文规模大体相称，无明显注水**。

**（一）实体真实性（有无造假）**：逐条核对 126 条实体的 evidence 与素材后确认，**全部实体均能在原文中找到出处，未发现凭空捏造的实体**（无"原文根本没有此名却建了实体"的造假）。但存在 **3 处明确的 evidence 段落号错误**和若干"偏松"引用（详见问题 7、8）。

**（二）与原文相称性缺口**：主要问题在**遗漏**而非造假。最严重的是**卫国世系本身出现两处断链**——**卫桓公（太子完）**、**卫襄公（恶）**两位国君未建实体；另有大量外涉君主、国邑、事件缺失（详见问题 1—6、11）。

**（三）世系完整性专项核对**（任务给定世系 vs 初稿 persons）：
- ✅ 已收：康叔、康伯、考伯、嗣伯、𢈻伯、靖伯、贞伯、顷侯、釐侯、共伯余、武公和、庄公扬、惠公朔、黔牟、懿公赤、戴公申、文公燬、成公郑、穆公遬、定公臧、献公衎、殇公剽、灵公元、出公辄、庄公蒯聩、悼公黔、敬公弗、昭公紏、怀公亹、慎公颓、声公训、成侯速、平侯、嗣君、怀君、元君、君角。
- ❌ **缺失**：**桓公（完）**（康叔世系中武公之前、庄公之后）、**襄公（恶）**（殇公、献公之后、灵公之前）。二者皆为卫国正式国君，直接导致世系链条断裂。
- 结论：38 代世系中初稿链上仅缺 2 代主体，但均为关键节点，**世系完整性不合格**。

**（四）重要事件在 events 中的体现**：初稿 15 条事件覆盖了三监之乱、州吁之乱、伋寿之死、左右公子之乱、齐襄公纳惠公、翟伐卫杀懿公、齐桓公筑楚丘、元咺之乱、孙宁逐献公、太子蒯聩出奔、孔悝之乱、赵简子围卫、卫绝祀等主干，**覆盖面较全**；但**惠公伐周立王子颓、共伯之死·武公代立、灵公卒·子郢让国·出公立、出公复归·悼公立、战国弑君（怀公弑昭公、慎公弑怀公）、卫更贬号**等本篇应记事件仍未立（详见问题 6）。

**1. 遗漏世系关键人物：卫桓公（太子完），应属 p9、p10、p11**

原文 p9"太子完立，是為桓公"、p10"州吁……襲殺桓公""迎桓公弟晉於邢而立之（宣公）"、p11"桓公"世系，均以桓公完为卫国君主。初稿 persons 中**既无 id `person:桓公`，亦无 `person:太子完`**，仅在"庄公扬"description 中以"太子完继位为桓公"一语带过。这是世系链第一个断点。建议补建实体，alias 收"太子完""完"，type=诸侯，dynasty=春秋，state=卫，evidence=[p9,p10,p11]。

**2. 遗漏世系关键人物：卫襄公（恶），应属 p27、p28、p29**

原文 p27"子襄公惡立"、p28"襄公六年"、p29"九年，襄公卒……立元為嗣，是為靈公"。初稿 persons 中**无襄公恶实体**，"公子斑师"description 仅以"襄公之孙"、灵公元 description 以"襄公之子"间接提及。这是世系链第二个断点（发生在献公→灵公之间）。建议补建，alias 收"恶""襄公"，evidence=[p27,p28,p29]。

**3. 世系旁支与国人人物遗漏：宁殖（甯惠子）、昭伯顽、伯姬、公子适、卫君瑕、庄姜（齐女）、戴妫（陈女女弟），应属 p24/p25、p17/p19、p37、p44、p22、p9**

- **宁殖（甯惠子）**：p24"孫文子、寗惠子"、p25 集解"甯惠子，甯殖也"，是与孙林父共逐献公的核心大夫，初稿只有其子"宁喜"，**缺宁殖本人**。
- **昭伯顽**：p17"黔牟之弟昭伯頑之子申（戴公）"、p19"其二曰昭伯"，为戴公、文公之父，缺。
- **伯姬（孔悝母）**：p37"取太子蒯聩之姊……適伯姬氏""悝母"，孔悝之乱关键人物，仅作"悝母"出现于孔悝 description，**未建实体**。
- **公子适**：p44"慎公父，公子適；適父，敬公也"，慎公之父，缺。
- **卫君瑕（公子瑕）**：p22"衞君瑕出犇"，与成公复位直接相关，缺。
- **庄姜（齐女）、戴妫（陈女女弟）**：p9 庄公所取齐女、陈女女弟（索隐明言"齊女即莊姜""女弟，戴媯也"），为桓公、州吁、伋、寿诸公子之母，缺。

**4. 外来君主与大夫大量遗漏，应分属 p25、p28、p30、p35、p10、p15、p45、p48、p11、p49、p23**

初稿对"外国"人物收录偏窄（仅收齐襄公、齐桓公、晋文公等）。以下均见于原文而初稿空缺：
- **齐景公**（p25"齊景公聞之"）、**晋平公**（p25"衞殤公會晉平公"）——渉及献公复位的关键外君。
- **楚灵王**（p28"楚靈王會諸侯"、p30"弒靈王"）、**晋昭公**（p30"朝晉昭公"）、**楚公子弃疾（楚平王）**（p30"楚公子弃疾弒靈王自立，為平王"）。
- **齐田乞、齐孺子、齐鲍子、齐悼公**（p35"齊田乞弒其君孺子""齊鮑子弒其君悼公"）。
- **陈侯**（p10，与石碏共谋杀州吁）、**郑伯弟段**（p10，州吁"求與之友"）。
- **周惠王、王子颓（穨）**（p15"周惠王犇溫，衞、燕立惠王弟穨為王"）。
- **公孙鞅**（p45"公孫鞅入秦"）、**始皇帝**（p48"立為始皇帝"）、**二世**（p48"二世廢君角"）。
- **鲁隐公、宋督（华督）、宋殇公、孔父（孔父嘉）、晋曲沃庄伯、晋哀侯**（p11 一组春秋外弑君事件）。
- **晋太子申生、骊姬**（p49 太史公曰引以类比）。
- **楚庄王、夏徵舒**（p23"楚莊王伐陳，殺夏徵舒"）。

**5. 国家（诸侯国）与地理实体遗漏：秦、魏、燕、郑、宋、陈、蔡、晋、鲁、齐，及东郡，应属 p47/p48、p15、p10/p11、p22/p23、p47**

初稿 places 中"诸侯国"仅收 **卫、邢** 两个。而原文大量以国名参与叙事：**秦**（p48 并天下、p47 拔魏东地）、**魏**（p47 囚杀怀君、徙卫野王）、**燕**（p15 与惠公共伐周）、**郑**（p15 复纳惠王、p23 围郑）、**宋/陈/蔡**（p10 三国许州吁、p11 弑君、p22 成公奔陈）、**晋/鲁/齐**（反复出现）。此外 **东郡**（p47"秦初置東郡"）作为秦置郡建制，亦未收。这些国家是理解卫国邦交的关键节点，建议至少补收秦、魏、晋、齐、郑、陈等常涉国。

**6. 重要事件遗漏，应分属 p7、p15、p33、p42、p44、p45/p47**

- **共伯之死·武公代立**（p7）：和袭攻共伯于墓上、共伯自杀、卫人立和为武公——本篇首个卫国内乱，仅在武公和 description 中体现，**未建 event**。
- **惠公伐周立王子颓**（p15）：惠公怨周容黔牟，与燕伐周、立王子颓——**未建 event**。
- **灵公卒·子郢让国·出公立**（p33）：子郢推辞、卫人立辄为出公——**未建 event**。
- **出公复归·悼公立**（p42）：石曼尃逐起、出公自齐复归、黔攻出公子自立——**未建 event**。
- **战国弑君系列**（p44）：公子亹弑昭公、公子颓弑怀公——**未建 event**。
- **卫更贬号**（p45"更貶號曰侯"、p47"更貶號曰君"）：战国削爵的关键政治事件——**未建 event**。

**7. evidence 段落号错误（实体确在原文，但所引段落不含该实体）**

逐条核对发现 3 处明确错误：
- **event:州吁之乱** evidence=["p10","p11"]：**p11 全段为"宣公七年，鲁弒隐公……"等外国弑君，无"州吁"字样**，应删除 p11。
- **concept:梓材** evidence=["p2","p3"]：**p3"成王长……举康叔为周司寇，赐卫宝祭器"及三家注均无"梓材"**，应删除 p3（梓材实见 p2，另见 p50 述赞"梓材有作"）。
- **person:庄公扬** evidence=["p8","p9","p10"]：**p10 起首即"桓公二年"，全段无"庄公"字样**，p10 引用不成立，应删除。
- 另有 **event:伋寿之死** evidence=["p12","p13"]：p13 仅提"前太子伋"，**无"寿"**，对"寿代死"而言 p13 属偏松引用（见问题 8）。

**8. evidence 覆盖偏松或覆盖不全（非造假，但不够严谨）**

除问题 7 外，以下实体的 evidence 存在"跨段过度引用"或"该实体明显出现却未引用"的情况：
- **event:伋寿之死** p13 不含"寿"，只宜作背景旁证；宜改系 p12。
- **place:卫** evidence=["p1","p5","p47","p48"] 偏窄——卫为全篇主体，p2/p3/p4 等处处出现，可补 p4（"子康伯代立"之卫君位）等，以支撑"始封—成长—末世"全链条。
- **event:孙宁逐献公** evidence=["p24","p25","p26"] 正确，但 description 混入"复纳献公、诛宁喜"（p25—p26），表述与 evidence 一致，此处无误，仅提示需保持这是两条事件的合并描述。

**9. 同人异名未归并 / alias 缺失与冲突**

- **一名多指未区分**：`person:庄公扬` 与 `person:庄公蒯聩` **均将 alias 写作"庄公"**，两实体同名 alias 冲突，检索"庄公"无法区分，应改为"庄公（扬）""庄公（蒯聩）"或注明世次。
- **异名未收全**：`person:康伯` 索隐明言"系本康伯名髡""即王孙牟也"，alias 仅收"牟伯""王孙牟"而**漏"髡"**；`person:共伯余` 索隐"恭伯名餘也"，**漏 alias"恭伯"**。
- **因实体缺失导致无法归并**：桓公=完、襄公=恶、楚公子弃疾=楚平王（"為平王"）、公孙鞅=商鞅（卫鞅），这些同人异名因主体未建而**无处归并**（呼应问题 1、2、4）。
- 已正确归并的示例（供对照）：子路/仲由/季路、高柴/子羔、孔圉/孔文子、石圃/石曼尃、般师/斑师、甯喜/宁喜，处理到位。

**10. 类型·朝代·国别字段问题**

- **朝代体例不一**：`person:周平王` dynasty="东周"，而其余周天子（周武王、成王、周夷王、厉王、宣王、幽王）均作"西周"，同一德类混用两套王朝分期，应统一。
- **type 体系不齐**：`person:周公旦` type="政治家"、`person:冉季` type="贵族"，与全篇主流类型（君主/诸侯/卿/大夫/公子/太子/夫人/家臣/乐人）不成体系，"政治家"为现代词汇，宜改为"宗室/卿"一类；冉季宜入"公子/宗室"。
- **state 归属存疑**：`person:武庚禄父` state="商"（其为纣子、封殷余民，宜作"殷/商"并注封地）；`person:仲由` state="卫"、`person:子羔` state="卫" 系因仕卫而系卫，可接受，但建议标注本籍（鲁/卫）以免误解为卫人。

**11. 关系型内容缺失（本稿无 relations 字段，关键关系仅散落于 description）**

初稿 JSON 顶层仅有 persons/places/events/concepts，**无独立关系（relations）结构**，导致大量应显式化的关系只能靠描述语句隐含。典型缺失：
- **弑君关系**：州吁弑桓公（p10）、公子亹弑昭公、公子颓弑怀公（p44）、齐田乞弑孺子、鲍子弑悼公（p35）——后三者连实体都缺，无从建关系。
- **出奔关系**：惠公奔齐（p13）、黔牟奔周（p14）、成公奔陈（p22）、献公奔齐（p24）、林父奔晋（p25）、太子蒯聩奔宋、之晋赵氏（p32）、起奔齐（p42）——"某奔某地"这一类应可作答的关系，仅在叙事中一句话带过，未结构化。
- **某地某人／赐封关系**：封孙文子于宿（p25）、齐置献公于聚邑（p24）、齐桓公为卫筑楚丘（p18）、徙卫野王（p47）。
- **亲属继承关系**：慎公父公子适、适父敬公（p44）；昭伯顽之子申为戴公（p17）——辈分链因当事人缺失而无法表达。

**校验汇总**：问题 **11** 条；遗漏实体 **40+ 处**（人物约 30、国邑约 11、事件约 6）；无凭空捏造实体，但有 3 处 evidence 段落号错误、1 处偏松。**最严重三问题**：① 世系断链——卫桓公（完）、卫襄公（恶）两位国君缺失；② 大量外涉君主与国邑实体缺位（齐景公/晋平公/楚灵王/齐田乞、秦魏晋齐郑陈等）；③ event:州吁之乱 等 3 处 evidence 段落号错误。
