# 万石张叔列传第四十三 校勘记

> 本记只列异文、通假、异体、古今字及疑似讹脱，**不改底本一字**。底本用字一律保留（繁体），白话译文行用规范简体。

## 一、通假字

| 段 | 底本 | 通 | 说明 |
|----|------|----|------|
| p0 | 能鼔琴 | 鼔＝鼓 | 「鼔」通「鼓」，弹奏。「鼔琴」即鼓琴。 |
| p2 | 僮僕訢訢如也 | 訢訢＝欣欣 | 「訢訢」通「欣欣」，和悦恭顺貌。 |
| p2 | 不譙讓 | 譙＝诮（一说） | 「譙让」即诮让，责骂、责备。 |
| p2 | 見路馬必式焉 | 式＝轼 | 「式」通「轼」，凭轼俯身致敬。 |
| p8 | 爲立石相祠 | — | 「石相祠」谓为石相（石庆）所立之祠。 |
| p11 | 倉廩旣空 | 廩＝廪 | 「廩」通「廪」，粮仓。 |
| p12 | 謚爲恬侯 | 謚＝谥 | 「謚」通「谥」，谥号。 |
| p16 | 坐酎金失侯 | 酎＝醇（一说） | 「酎金」为汉宗庙八月饮酎之金，诸侯献金不合即夺爵。 |
| p17 | 妄意不疑 | 亡＝无 | p17「前郎亡金者」之「亡」通「无」，失去。 |
| p19 | 期爲不絜清 | 絜＝洁 | 「絜」通「洁」，洁净。 |
| p23 | 有可郤，郤之 | 郤＝却 | 「郤」通「却」，退回、驳回。 |
| p25 | 周文處讇 | 讇＝谄 | 「讇」通「谄」，谄媚。 |

## 二、异体字、古今字

| 段 | 底本 | 今体 | 说明 |
|----|------|------|------|
| 篇题 | 萬石張叔列傳 | 万石张叔列传 | 「萬」今作「万」。 |
| p2 | 雖燕居必冠 | — | 「燕居」即闲居。 |
| p2 | 羣臣 | 群臣 | 「羣」为「群」异体（p21 同）。 |
| p7 | 元朔五年 | — | 「元朔」「元狩」「元鼎」「元封」「太初」皆汉武帝年号。 |
| p10 | 兒寬 | 倪宽 | 「兒」为姓氏「倪」的古写（兒宽，漢武帝时儒者）。 |
| p11 | 慙 | 惭 | 「慙」为「惭」异体（p5、p11 同）。 |
| p13 | 衞綰 | 卫绾 | 「衞」为「卫」异体。 |
| p14 | 賜之劔 | 赐之剑 | 「劔」为「剑」异体。 |
| p17 | 大慙 | 大惭 | 异体。 |
| p21 | 祕戲 | 秘戏 | 「祕」为「秘」异体。 |
| p25 | 訥於言而敏於行 | 讷于言而敏于行 | 引《论语·里仁》，「於」今作「于」。 |

## 三、异文、存疑

| 段 | 底本 | 异文/他本 | 说明 |
|----|------|-----------|------|
| p4 | 取親中裙廁牏 | 一说「牏」为便器，一说为贴身小衣 | 两说并存，底本照录。 |
| p11 | 無名數者四十萬 | — | 「名数」谓户籍名册，无名数即无户籍。 |
| p13 | 綰以戲車爲郎 | — | 「戏车」为汉时一种车上杂技，以之选郎。 |
| p14 | 劔尚盛 | — | 「盛」谓盛放于匣中。 |
| p15 | 誅栗卿之屬 | — | 栗卿即栗姬之亲族（栗太子之属）。 |
| p20 | 以醫見 | — | 「以医见」谓凭医术被进用。 |
| p23 | 安丘侯說之庶子 | — | 「说」为安丘侯之名（张说）。 |

## 四、校勘结论

- 底本用字与今体差异主要为通假与异体，**不影响文义**者从底本照录；
- 「中裙厕牏」「戏车」「无名数」等处属名物、制度，已出校说明；
- 白话译文行统一用规范简体，人名地名从今通行写法（石奋、石建、石庆、卫绾、直不疑、周仁、张欧、兒宽等）。
