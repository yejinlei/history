# 廉颇蔺相如列传第二十一 · 翻译互校报告

**互校单元**：独立于翻译单元，对照原典与三家注逐段核验
**原译者**：翻译单元初稿
**共提出 18 条意见**：径改 3 条、补译注 12 条、存疑 1 条、体例 2 条

---

## 一、径改（译文错误或不达意，直接改正）

| 段 | 问题 | 改正 |
|---|---|---|
| p1 | "肉袒伏斧质请罪"译为"袒露上身伏在斧质（刑具）上请罪"——"斧质"即腰斩刑具，但"肉袒"兼有"负荆请罪"之意前奏，译"袒露上身伏在刑具上请罪"更准 | 改正 |
| p2 | "广成传舍"译为"广成传舍"——"传"读 zhuàn，驿舍，应在译文中出音注并译"广成驿馆" | 改译为"广成驿馆"并注音 |
| p11 | "胥后令邯郸"初译为"等回到邯郸后再听候命令"——《索隐》明言"'邯郸'二字当为'欲战'二字之讹"，译文必须出此歧说而不能直接采纳某一说 | 改为"胥，待也。待后令——'邯郸'二字或说为'欲战'之讹，谓临战再听令" |

## 二、补译注（文意可解但有必要加注）

| 段 | 待补 | 说明 |
|---|---|---|
| p0 | "阳晋"原注已出地望，但"有本作晋阳非也"是重要版本问题，应在注中明说 | 补注 |
| p2 | "章台"非正殿，只是秦宫一台观，秦王在章台而非正殿接见，本身就是倨慢——应加注说明章台非朝会正殿 | 补注 |
| p2 | "九宾礼"原注已出周礼九仪，但"秦赵何得九宾？但亦陈设车辂文物耳"（正义刘伯庄说）是关键，必须补入 | 补入正义说 |
| p6 | "渑池"属"西河外"的"外"字——渑池在西河之南，对秦而言为"外"，应说明 | 补注 |
| p6 | "盆缻"缶（fǒu），秦声以击缶为节，"请以颈血溅大王"是五步之内以死相拼，可补注"五步之内谓近在咫尺，秦兵不能救" | 补注 |
| p7 | "位在廉颇之右"——秦汉以前以右为尊，职高者名列于右方（非"右相")，应明确"右"即上位 | 补注 |
| p7 | "刎颈之交"即生死之交——可补崔浩说"言要齐生死而刎颈无悔也" | 补注 |
| p8 | "几"邑有属齐属魏二说，赵世家作攻魏之几——应在注中说明版本歧说 | 补注 |
| p11 | "两鼠斗于穴中"译"就好比两只老鼠在洞穴中搏斗"已可，但"将勇者胜"可再强调"狭路相逢，无回旋余地" | 补注 |
| p13 | "胶柱而鼓瑟"——把瑟上调弦的柱胶粘住，则弦不能调、音不能变，喻拘泥不知变通，应详注 | 补注 |
| p17 | "天下以市道交"——按做生意的道理与人交往，即趋利附势，应译得更白 | 补译 |
| p23 | "百金之士"即勇士、敢死之士——《管子》"能破敌擒将者赏百金"，应补注 | 补注 |

## 三、存疑（需后续定稿裁定）

| 段 | 问题 | 说明 |
|---|---|---|
| p19 | "一饭斗米，肉十斤"——廉颇饭量是否真实？史公笔法意在表现廉颇被谗。译文如实翻译即可，不必论真伪；但可加注"此为使者谗言之前的表现，反衬郭开之毁" | 存疑，定稿酌加 |

## 四、体例

| 项 | 意见 |
|---|---|
| 本篇为多人合传 | 廉颇、蔺相如、赵奢、李牧四正传，赵括、许历、赵括母、郭开等附传——定稿要注意人物线切换的提示语是否清晰 |
| 成语密度 | 本篇出成语最多：完璧归赵、怒发冲冠、负荆请罪、刎颈之交、胶柱鼓瑟、纸上谈兵（括徒读父书）、两鼠斗穴——定稿可考虑在增强层统一列 |

---

**处理意见**：径改 3 条在定稿中直接改正；补译注 12 条在定稿逐条落实；"斗米肉十斤"由定稿酌加；体例问题在定稿与增强层统一处理。
