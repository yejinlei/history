# 《史记·魏豹彭越列传第三十》校勘记

底本：百衲本/中华书局点校本繁体正文，含索隐、正义、集解古注。以下逐段列出通假字、异体字、重要异文及专有名词古写法。

| 段落 | 原文用字 | 类型 | 说明 |
|------|----------|------|------|
| p0 | 寗陵君 | 异体字 | "寗"为"寧"（宁）的异体，寗陵即宁陵，汉县名，故地在今河南宁陵。晋灼注"即今寧陵是"，知古本亦作"寧"，"寗"为后世刻本异体。 |
| p0 | 家人 | 古今异义 | 非指家属，乃指"庶人、平民"。秦灭魏，迁魏咎为庶人。 |
| p0 | 王（陳勝之起王也） | 破读 | 音 wàng，称王，动词。正义注"于放反"。 |
| p0 | 徇 | 通假/古义 | 通"徇"，巡行略地，攻取之义。 |
| p0 | 昬亂 | 异体字 | "昬"为"昏"的异体（避唐太宗讳改"民"旁之例，此处为古写），指天下昏乱。索隐引老子"国家昏亂有忠臣"，是"昏""昬"同字异写。 |
| p0 | 畔 | 通假字 | 通"叛"，背叛。"天下共畔秦"即天下共叛秦。下文"畔漢""畔項王"并同。 |
| p0 | 五反 | 通假字 | "反"通"返"，往返五次。指周市五次赴陈迎魏咎，陈王始遣之。 |
| p1 | 臨濟 | 地名古写 | 临济，故城在今河南开封一带（正义注淄州高苑县北者为另一临济，需辨）。魏王咎被章邯围于此。 |
| p1 | 自燒殺 | 专名/史实 | 即自焚，魏咎与民约降后自烧而死，以全其民。 |
| p1 | 項它、田巴 | 人名古写 | "它"音 tuō，楚将；田巴，齐将。"它"不读 tā。 |
| p2 | 河東、平陽 | 地名 | 河东郡，平阳为西魏国都，在今山西临汾西南。 |
| p2 | 西魏王 | 封号 | 项羽分封，徙魏王豹为西魏王，王河东，因在魏国西部大梁以西而称"西魏"。 |
| p2 | 漢元年 | 纪年专名 | 公元前206年，刘邦被封汉王之年。 |
| p3 | 三秦 | 专名 | 项羽封秦三降将章邯、司马欣、董翳于关中，合称三秦。 |
| p3 | 臨晉 | 地名 | 临晋关，在今陕西大荔朝邑东，黄河重要渡口。正义注"在同州朝邑縣界"。 |
| p3 | 彭城 | 地名 | 项羽西楚都城，今江苏徐州。 |
| p3 | 滎陽 | 地名 | 今河南荥阳东北，楚汉相争主战场之一。 |
| p3 | 河津 | 专名 | 黄河渡口，此指临晋关、蒲津一带。"絕河津畔漢"即切断黄河渡口叛汉。 |
| p3 | 酈生 | 人名省称 | 即郦食其（lì yì jī），刘邦说客。"生"为先生省称。 |
| p3 | 緩頰 | 古语 | 婉言劝说，非动武。 |
| p3 | 一世閒 | 异文 | "閒"通"間"，"一生一世间"。今本多作"一世間"。即"人生一世间"。 |
| p3 | 白駒過隙 | 成语出典 | 索隐引庄子"騏驥之馳過隙"；小颜（颜师古）谓"白驹"指日影，隙为壁隙，言时光迅疾。 |
| p3 | 慢而侮人 | 古义 | 傲慢侮辱人，骂诸侯群臣如骂奴仆。 |
| p3 | 傳詣 | 专名 | 用传车押送到。"傳" zhuàn，驿车。 |
| p3 | 河東、太原、上黨 | 郡名 | 魏豹国被灭后置三郡，见集解引高祖本纪。 |
| p4 | 昌邑 | 地名 | 秦县，故地在今山东巨野东南、金乡西北。汉武改为昌邑国。 |
| p4 | 鉅野澤 | 水名古写 | 即巨野泽，又称大野泽，古代大湖，在今山东巨野北，梁山泺之前身。"鉅"为"巨"之古写。 |
| p4 | 羣盜 | 古今异义 | "盜"此处非贬义之窃贼，指聚众于泽中反抗官府者，犹"群豪"。 |
| p4 | 豪桀 | 异体字 | "桀"通"傑"，豪杰。 |
| p5 | 澤閒 | 通假字 | "閒"通"間"，泽中。 |
| p5 | 彊請 | 通假字 | "彊"通"强"（qiǎng），强请、坚决请求。下文"彊以爲長"并同。 |
| p5 | 旦日 | 古语 | 明日、第二天一早。索隐"謂明日之朝日出時也"。 |
| p5 | 後期 | 古义 | 迟到、超过约定时间。"後期者斬"即迟到者斩。 |
| p5 | 校長 | 古义异读 | 非后世之学校校长，乃军中低级武官之长（校尉之长的属吏），警卫头目。 |
| p5 | 設壇祭 | 专名 | 筑坛祭祀，彭越以此立威。 |
| p6 | 碭 | 地名/音读 | 砀郡，砀县，音 dàng，正义"徒郎反"。今安徽砀山。 |
| p6 | 項籍 | 人名 | 即项羽，字籍（羽是字）。史书项籍、项羽互见。 |
| p6 | 毋所屬 | 通假字 | "毋"通"無"，无所归属。 |
| p6 | 田榮 | 人名 | 齐王田荣，最先叛项羽者。 |
| p6 | 濟陰 | 地名 | 郡名，治所在今山东定陶西北。 |
| p6 | 蕭公角 | 人名/官称 | 楚萧县令名角。楚称县令为"公"，故称萧公角。正义"蕭縣令。楚縣令稱公；角，名"。 |
| p6 | 外黃 | 地名 | 今河南民权西北。 |
| p6 | 魏相國 | 官名 | 魏相国，彭越被拜此职，专将兵略梁地。"擅猶專也"，索隐。 |
| p7 | 河上 | 地名 | 滑州河上，在今河南滑县一带黄河边。 |
| p7 | 游兵 | 军事术语 | 即后世游击战之雏形，往来游击楚军。"彭越撓楚"典故所出。 |
| p7 | 睢陽 | 地名 | 今河南商丘南，正义"宋州宋城"。 |
| p7 | 相距 | 通假字 | "距"通"拒"，对峙。 |
| p7 | 成皐 | 地名/异体 | "皐"为"皋"之异体，成皋，在今河南荥阳汜水镇。正义"河南府氾水是"。 |
| p7 | 穀城 | 地名 | 在今山东平阴东阿镇，正义"齊州東阿縣東二十六里"。 |
| p7 | 陽夏 | 地名/音读 | 音 jiǎ，今河南太康。正义"夏，古雅反。陳州太康縣也"。 |
| p7 | 斛 | 量名 | 古容量单位，十斗为斛，十余万斛即百余万斗粮。 |
| p8 | 固陵 | 地名 | 在今河南淮阳西北，正义"陳州宛丘縣西北三十二里"。刘邦追项羽于此被败。 |
| p8 | 留侯 | 封号 | 即张良，封留侯。 |
| p8 | 毋後 | 通假字 | "毋"通"無"，魏豹死后无后继人为魏王。 |
| p8 | 蚤定 | 通假字 | "蚤"通"早"，早定（封王之约）。 |
| p8 | 傅海 | 通假字 | "傅"通"附"，靠近、连接到海。集解"音附"。 |
| p8 | 捐此地 | 古义 | 弃此地（分与二人），弃捐。 |
| p8 | 垓下 | 地名 | 在今安徽灵璧南（一说河南鹿邑），楚汉决战地。正义"在亳州也"。 |
| p8 | 定陶 | 地名 | 今山东菏泽定陶区，梁国都。正义"曹州"。 |
| p9 | 朝陳、長安 | 专名 | 六年朝于陈（陈县，今河南淮阳，会诸侯擒韩信处）；九年十年朝于长安。 |
| p10 | 陳豨 | 人名 | 陈豨（xī），代相，汉十年反于代地。 |
| p10 | 代地、邯鄲 | 地名 | 代在今河北蔚县一带；邯郸，赵都，今河北邯郸，刘邦亲征至此。 |
| p10 | 讓 | 古义 | 责备、谴责，非谦让。 |
| p10 | 扈輒 | 人名 | 彭越将，劝越反者。 |
| p10 | 禽 | 通假字 | 通"擒"，被擒。 |
| p10 | 太僕 | 官名 | 掌车马之官，此为梁国太仆，亡走告彭越反。 |
| p10 | 掩 | 古义 | 掩捕、乘其不备而捕。 |
| p10 | 雒陽 | 地名异体 | "雒"为"洛"古写，洛阳，汉高帝都。 |
| p10 | 反形已具 | 法律术语 | 谋反的情形已经具备。集解引张晏、瓒两说：张以为有司非，瓒以不诛扈辄即为反形具。 |
| p10 | 傳處 | 专名 | 用驿车送往安置。"傳" zhuàn。 |
| p10 | 蜀青衣 | 地名 | 青衣县，在蜀，今四川雅安芦山一带。文颖曰"在蜀"，瓒曰"今漢嘉是也"，索隐以瓒说为是。 |
| p10 | 鄭 | 地名 | 今陕西华县（华州区），属京兆。索隐"地理地鄭屬京兆"，正义"華州"。彭越西徙途中于郑遇吕后。 |
| p10 | 呂后 | 人名 | 即吕雉，汉高祖后。 |
| p10 | 自遺患 | 古语 | 给自己留下祸患，"遺" wèi，遗留。 |
| p10 | 舍人 | 官名 | 王公贵官左右亲近之臣，家臣。吕后令彭越舍人告其复谋反。 |
| p10 | 廷尉王恬關 | 人名/职官 | 廷尉，主刑狱之官；王恬开（"關"应为"開"，形近而讹，王恬开，《汉书》作王恬启，避景帝讳改）。奏请族诛。 |
| p10 | 夷三族 | 刑名 | 灭三族之酷刑。"夷"，灭。 |
| p10 | 國除 | 专名 | 封国被废除。 |
| p11 | 席卷 | 古语 | 如卷席般占有，形容攻取之速。 |
| p11 | 南靣稱孤 | 专名/异体 | "靣"为"面"之异体；南面称王，古代君主坐北朝南称孤道寡。 |
| p11 | 喋血 | 异文/通假 | 音 dié，践血而行。集解徐广曰"一作'唼'"，唼（shà）为喋之别体；索隐"喋猶踐也"，谓杀敌践血而行。 |
| p11 | 畔逆 | 通假字 | 通"叛逆"。 |
| p11 | 虜囚 | 古义 | 被俘虏囚禁。 |
| p11 | 被刑戮 | 古义 | 遭受刑罚诛戮。"被"，遭受。 |
| p11 | 中材已上 | 通假字 | "已"通"以"，中等才智以上的人。 |
| p11 | 攝尺寸之柄 | 古语 | 执掌一点点权柄。"攝"，持、执掌。 |
| p11 | 雲蒸龍變 | 比喻语 | 如云气蒸腾、龙蛇变化，喻乘时奋起。 |
| p11 | 幽囚 | 古义 | 囚禁。 |
| p12 | 述贊 | 文体名 | 索隐述赞，司马贞为每传所作四言韵语赞辞。 |
| p12 | 葅醢 | 刑名异体 | "葅"同"菹"（zū），菹醢（hǎi），把人剁成肉酱之酷刑，即p12赞语所指彭越被醢刑。 |
| —— | 薄姬 | 背景人物异文 | 本传正文未载薄姬事，见《外戚世家》；薄姬为魏豹姬，豹死后入刘邦后宫生汉文帝。此点需读者合参。 |
| —— | 欒布 | 背景人物 | 本传正文未载栾布哭彭越事，见于《季布栾布列传》；赞语"徵兵不往"指彭越谢病不征邯郸事。 |
| —— | 醢彭越遍賜諸侯 | 背景史实 | 本传正文未详载"醢为肉酱遍赐诸侯"事，见《黥布列传》："汉诛梁王彭越，醢之，盛其醢遍赐诸侯。至淮南，淮南王方猎，见醢，因大恐，阴令人部聚兵，候伺旁郡警急。"英布因此反。 |
