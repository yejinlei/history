# 《史记·匈奴列传第五十》翻译校验报告

> 逐段核对底本原文与白话译文，确保实词、人名、地名、关键字准确，原文行逐字与底本一致。

---

## 总体说明
本次翻译以百衲本《史记》为底本，参考中华书局点校本及通行白话译本，逐段核对：
1. 原文行逐字与底本完全一致，异体字、通假字全部保留，未替换为通用简化字。
2. 人名、地名统一采用史书记载标准称谓，跨篇人名与已完成列传一致（如「劉邦（漢高祖）」「劉恆（漢文帝）」等，与李将军列传、韩长孺列传保持一致）。
3. 索隐述赞按体例保留原文，不逐句硬译，分条语词典释，符合规范。
4. 长段引文（文帝、单于书信）完整翻译，未删减内容。

## 分段订正项
| 段号 | 原文 | 原译问题 | 订正结果 |
|------|------|----------|----------|
| p0 | 劉伯莊云亦然 | 原未注明刘伯莊身份 | 已补充译注：「劉伯莊：唐代学者，著有《史记音义》等」 |
| p1 | 奇畜則橐駞、驢、驘、駃騠、騊駼、驒騱 | 原未注明特殊牲畜名称读音 | 已补充译注标注读音：駃騠jué tí、騊駼táo tú、驒騱tuó xí |
| p1 | 士力能彎弓 | 原译「成年男子都能拉开弓」 | 补充「彎弓」即拉满弓，强调力量标准 |
| p2 | 變于西戎，邑于豳 | 原译「在西戎地区改变风俗」 | 订正为「在西戎地区改变习俗，在豳地建城居住」，补充「邑」为建城作都邑 |
| p2 | 命曰「荒服」 | 原译「叫做荒服」 | 补充译注说明五服制度，荒服为五服最远一等，只须进贡不强制政令 |
| p2 | 甫刑之辟 | 原译「《甫刑》的法律」 | 订正为「《甫刑》的刑法」，「辟」即刑法，《甫刑》即《吕刑》 |
| p3 | 莫能相一 | 原译「没有人能统一」 | 保留准确，补充译注说明一百多个戎部互不统属 |
| p4 | 築長城，自代並陰山下 | 原译「从代地沿阴山而下」 | 补充「並」通「傍」，即沿着阴山修筑，与底本通假字说明一致 |
| p4 | 與荊軻刺秦王秦舞陽者，開之孫也 | 原译「和荆轲一起刺秦王的秦舞阳」 | 补充译注说明秦舞阳年十三杀人，刺秦时胆怯事，与刺客列传一致 |
| p6 | 鳴鏑 | 原译「响箭」 | 补充译注：鸣镝为冒顿特制发号施令用，射出去带响声，是鸣镝弑父典故核心器物 |
| p7 | 控弦之士三十餘萬 | 原译「能拉弓射箭的士兵三十多万」 | 保留准确，「控弦之士」即骑兵部队，说明此时匈奴军力鼎盛 |
| p9 | 二十四長 | 原译「二十四位长官」 | 补充译注说明匈奴万骑制度，二十四长是核心军事贵族，分统全国骑兵 |
| p10 | 拔刃尺者死 | 原译「拔刀出鞘一尺就判死刑」 | 保留准确，说明匈奴法律简约，斗殴杀人者死 |
| p10 | 獄久者不過十日，一國之囚不過數人 | 原译「坐牢最长不超过十天，全国囚犯不过几人」 | 保留准确，体现匈奴法律简易、监狱少的特点，与中原繁琐法律形成对比 |
| p12 | 漢兵中外不得相救餉 | 原译「汉军内外无法相互救济军粮」 | 订正为「汉军被围的内外部队无法相互救援、输送军粮」，「中外」指包围圈内外 |
| p12 | 持滿傅矢外鄉 | 原译「拉满弓搭上箭面朝外」 | 补充「傅」通「附」，即箭搭在弦上；「鄉」通「向」，面向外，保持戒备状态突围 |
| p14 | 冒頓乃爲書遺高后，妄言 | 原译「冒顿写信给高后，言辞轻佻无礼」 | 补充译注说明信件具体内容「两主不乐，无以自虞，愿以所有，易其所无」，是公然挑衅，对应高后欲击之事 |
| p19 | 必我行也，為漢患者 | 原译「一定要我去，我将成为汉朝的祸患」 | 保留准确，中行说后来确实成为匈奴谋主，教匈奴对抗汉朝，为文帝朝匈奴大患 |
| p22 | 父子兄弟死，取其妻妻之，惡種姓之失也 | 原译「娶他们的妻子为妻，是担心种族消失」 | 补充译注说明收继婚制度的经济和社会原因：防止财产外流、保证家族种姓延续，不同于中原伦常 |
| p22 | 嗟土室之人，顧無多辭 | 原译「住在土石房屋里的汉人啊，不要多话」 | 保留准确，「土室之人」是中行说对汉人的蔑称，体现游牧文明对农耕定居文明的文化偏见 |
| p24 | 候騎至雍甘泉 | 原译「侦察骑兵到达雍地甘泉宫」 | 订正为「侦察骑兵到达雍地、甘泉宫」，甘泉宫距离长安仅三百里，震动关中，以此说明此次入侵严重程度 |
| p30 | 馬邑之謀 | 补充说明马邑之谋是汉匈关系转折点，从此断绝和亲，开启大规模战争 |
| p31 | 蘢城 | 原译「茏城」 | 注明即龙城，匈奴祭天圣地，卫青此战是汉朝对匈奴首次大胜，打破匈奴不可战胜神话 |
| p36 | 破得休屠王祭天金人 | 原译「缴获休屠王祭天金人」 | 补充译注：祭天金人为匈奴祭天用的铜像，后世传为佛教传入中国之始，是重要文化事件 |
| p40 | 封於狼居胥山，禪姑衍，臨翰海 | 原译「在狼居胥山祭天，姑衍祭地，到翰海回师」 | 补充「封」是祭天、「禪」是祭地，是古代帝王祭天地的大礼，霍去病以武将身份行封禅礼，是古代武将最高荣誉，即「封狼居胥」典故来源 |
| p61 | 唯在擇任將相哉 | 原译「关键在于选择任用将相啊」 | 补充译注：司马迁论赞重复两遍，是对汉武帝用人不当（如宠信李广利、李陵事件）的强烈感慨，体现司马迁对伐匈奴战争的反思 |
| p62索隐述赞 | 原未逐句译 | 按体例保留原文，分条语词典释，符合规范，不逐句硬译 |
