# 平津侯主父列传第五十二·白话初稿

## 原文与译文

### p0
**原文**：丞相公孫弘者，齊菑川國薛縣人也，⟦0⟧⟦1⟧字季。少時爲薛獄吏，有辠，免。家貧，牧豕海上。年四十餘，乃學春秋雜說。養後母孝謹。

**译文**：丞相公孙弘，是齐地菑川国薛县人，字季。他年轻时做过薛县的狱吏，因犯罪被免官。家中贫困，他在海边牧猪。四十多岁时，才学习《春秋》及各家杂说。他奉养后母十分孝顺谨慎。

**译注**：
- 菑川國：西汉诸侯王国，都剧县（今山东寿光南）。⟦0⟧⟦1⟧为三家注序号，原样保留。
- 薛縣：菑川国属县，在今山东滕州南。
- 有辠：有罪；辠，古「罪」字。
- 牧豕海上：在海边放猪；海上指渤海之滨。
- 春秋雜說：《春秋》经及各家解释《春秋》的杂传学说。

### p1
**原文**：建元元年，天子初即位，招賢良文學之士。是時弘年六十，徵以賢良爲博士。使匈奴，還報，不合上意，上怒，以爲不能，弘迺病免歸。

**译文**：建元元年，汉武帝刚刚即位，下诏招选贤良文学之士。这时公孙弘已经六十岁，以贤良身份被征召，任为博士。他奉命出使匈奴，回来汇报情况，不合皇上心意，皇上发怒，认为他无能，公孙弘于是称病免官回乡。

**译注**：
- 建元元年：公元前140年，汉武帝第一个年号。
- 賢良文學：汉代察举科目，由郡国推举品行端正、通经学的士人。
- 博士：秦汉时掌通古今、备顾问的学官。
- 使匈奴：出使匈奴。
- 迺：同「乃」。

### p2
**原文**：元光五年，有詔徵文學，菑川國復推上公孫弘。弘讓謝國人曰：「臣已嘗西應命，以不能罷歸，願更推選。」國人固推弘，弘至太常。太常令所徵儒士各對策，百餘人，弘第居下。策奏，天子擢弘對爲第一。召入見，狀貌甚麗，拜爲博士。是時通西南夷道，置郡，巴蜀民苦之，詔使弘視之。還奏事，盛毀西南夷無所用，上不聽。

**译文**：元光五年，皇帝下诏征召文学之士，菑川国又推荐公孙弘。公孙弘向国人辞让说：「我已经西去应过诏命，因为无能被罢归，希望改推别人。」国人坚持推举公孙弘，公孙弘到了太常那里。太常让所征召的一百多名儒士各自对策，公孙弘的等次排在最下。对策奏上后，天子把公孙弘的对策提拔为第一。召入相见，见他相貌堂堂，任为博士。这时正在开通西南夷的道路，设置郡县，巴蜀百姓为此困苦，下诏派公孙弘去视察。他回来奏报情况，极力诋毁西南夷没有用处，皇上没有听从。

**译注**：
- 元光五年：公元前130年。
- 太常：九卿之一，掌宗庙礼仪、选试博士。
- 對策：应诏回答皇帝关于政事的提问。
- 擢：提拔。
- 西南夷：指今四川南部、云南、贵州一带的少数民族。
- 巴蜀：巴郡、蜀郡，今四川重庆一带。

### p3
**原文**：弘爲人恢奇多聞，常稱以爲人主病不廣大，人臣病不儉節。弘爲布被，食不重肉。後母死，服喪三年。每朝會議，開陳其端，令人主自擇，不肯面折庭爭。於是天子察其行敦厚，辯論有餘，習文法吏事，而又緣飾以儒術，⟦0⟧上大說之。二歲中，⟦1⟧至左內史。弘奏事，有不可，不庭辯之。嘗與主爵都尉汲黯請間，汲黯先發之，弘推其後，天子常說，所言皆聽，以此日益親貴。嘗與公卿約議，至上前，皆倍其約以順上旨。汲黯庭詰弘曰：「齊人多詐而無情實，始與臣等建此議，今皆倍之，不忠。」上問弘。弘謝曰：「夫知臣者以臣爲忠，不知臣者以臣爲不忠。」上然弘言。左右幸臣每毀弘，上益厚遇之。

**译文**：公孙弘为人雄伟奇异、见闻广博，常说人主的毛病在于心胸不广大，人臣的毛病在于不节俭。公孙弘盖布被，吃饭不吃两种以上的肉菜。后母去世，他服丧三年。每逢朝会议事，他只是开陈事情的端绪，让皇上自己抉择，不肯当面驳斥、当庭争辩。于是天子察觉他品行忠厚，辩论有余，熟习文书法令和官吏事务，又能用儒术加以文饰，皇上非常喜欢他。两年之中，官至左内史。公孙弘奏事，有不被采纳的，不在朝廷争辩。他曾和主爵都尉汲黯请求单独接见，汲黯先提出问题，公孙弘随后推阐，天子常常很高兴，所说的都听从，因此日益亲贵。他曾与公卿约好提议的内容，到了皇上面前，却全部违背约定来顺从皇上意旨。汲黯当庭诘责公孙弘说：「齐人多欺诈而无真情，起初和我们一起提出这个建议，现在全都违背，这是不忠。」皇上问公孙弘，公孙弘谢罪说：「了解我的人认为我忠诚，不了解我的人认为我不忠诚。」皇上认为公孙弘的话对。皇上身边的宠臣常常诋毁公孙弘，皇上却越发厚待他。

**译注**：
- 恢奇：雄伟奇异，气概非凡。
- 病：缺陷、毛病。
- 食不重肉：一餐不吃两种肉食，形容节俭。
- 面折庭爭：当面驳斥、在朝廷上争辩。
- 緣飾以儒術：用儒家学说来文饰。
- 說：同「悦」。
- 左內史：官名，掌治京师，后改名左冯翊。
- 主爵都尉：九卿之一，掌列侯事务。
- 請間：请求单独接见（避开众人奏事）。
- 倍：通「背」，违背。
- 庭詰：在朝廷上责问。

### p4
**原文**：元朔三年，張歐免，以弘爲御史大夫。是時通西南夷，東置滄海，北築朔方之郡。弘數諫，以爲罷敝中國以奉無用之地，願罷之。於是天子乃使朱買臣等難弘置朔方之便。發十策，弘不得一。⟦0⟧⟦1⟧弘迺謝曰：「山東鄙人，不知其便若是，願罷西南夷、滄海而專奉朔方。」上乃許之。

**译文**：元朔三年，张欧被免官，以公孙弘为御史大夫。这时正在开通西南夷，东边设置沧海郡，北边修筑朔方郡。公孙弘屡次劝谏，认为这是使中国疲惫来奉养无用之地，希望停止这些工程。于是天子就派朱买臣等人以设置朔方郡的便利来责难公孙弘。提出十个问题，公孙弘一个也答不上。公孙弘于是谢罪说：「我是山东的鄙陋之人，不知道设置朔方郡有这样的便利，希望停止经营西南夷、沧海郡而专门奉事朔方。」皇上这才答应了他。

**译注**：
- 元朔三年：公元前126年。
- 張歐：西汉大臣，时为御史大夫。
- 御史大夫：三公之一，副丞相，掌监察。
- 滄海：沧海郡，在今朝鲜半岛中部。
- 朔方：朔方郡，在今内蒙古河套一带，元朔二年置。
- 罷敝：通「疲弊」，使疲惫困乏。
- 朱買臣：西汉大臣，时为中大夫，以善《春秋》《楚辞》著称。
- 難：诘难、反驳。
- 山東：崤山以东，泛指关东地区。
- 不得一：一个也答不上来。

### p5
**原文**：汲黯曰：「弘位在三公，奉祿甚多。然爲布被，此詐也。」上問弘。弘謝曰：「有之。夫九卿與臣善者無過黯，然今日庭詰弘，誠中弘之病。夫以三公爲布被，誠飾詐欲以釣名。且臣聞管仲相齊，有三歸，侈擬於君，桓公以霸，亦上僭於君。晏嬰相景公，食不重肉，妾不衣絲，齊國亦治，此下比於民。⟦0⟧今臣弘位爲御史大夫，而爲布被，自九卿以下至於小吏，無差，誠如汲黯言。且無汲黯忠，陛下安得聞此言。」天子以爲謙讓，愈益厚之。卒以弘爲丞相，封平津侯。⟦1⟧⟦2⟧

**译文**：汲黯说：「公孙弘位在三公，俸禄很多，却盖布被，这是欺诈。」皇上问公孙弘，公孙弘谢罪说：「有这事。九卿中和我交好的没有超过汲黯的，然而今天他当庭责问我，确实说中了我的毛病。以三公的身份却盖布被，确实是巧饰欺诈想以此沽名钓誉。况且我听说管仲做齐国相，有三归之台，奢侈可比国君，齐桓公靠他称霸，这是对上僭越了君主。晏婴做齐景公相，吃饭不吃两样肉，妾不穿丝织品，齐国也治理得很好，这是向下等同于百姓。如今我公孙弘位为御史大夫，却盖布被，使从九卿以下直到小吏没有贵贱差别，确实如汲黯所说。况且没有汲黯的忠诚，陛下怎能听到这些话。」天子认为公孙弘谦让，越发厚待他。最终以公孙弘为丞相，封为平津侯。

**译注**：
- 三公：汉代指丞相、太尉、御史大夫，为最高官位。
- 奉祿：俸禄；奉通「俸」。
- 管仲：春秋时齐桓公相，辅佐桓公称霸。
- 三歸：说法不一，或谓三归台，或谓娶三姓女，或谓市租之税，此指管仲有三归之富。
- 侈擬於君：奢侈可与国君相比。
- 僭：僭越，超越本分。
- 晏嬰：春秋时齐景公相，以节俭著称。
- 下比於民：向下与平民等同。
- 平津侯：封于平津乡（今河北盐山东南），食邑六百五十户。公孙弘是西汉第一个以丞相封侯的人。

### p6
**原文**：弘爲人意忌，外寬內深。⟦0⟧諸嘗與弘有郤者，雖詳與善，陰報其禍。殺主父偃，徙董仲舒於膠西，皆弘之力也。食一肉脫粟之飯。⟦1⟧故人所善賔客，仰衣食，弘奉祿皆以給之，家無所餘。士亦以此賢之。

**译文**：公孙弘为人猜疑忌恨，外表宽和，内心深险。那些曾与他有嫌隙的人，他虽然假装与他们交好，暗中却报复加祸。杀主父偃，把董仲舒调任胶西相，都是公孙弘的力量。他每餐只吃一个肉菜和糙米饭。老朋友和他交好的宾客，仰赖他供给衣食，公孙弘的俸禄都用来供给他们，家中没有余财。士人也因此认为他贤明。

**译注**：
- 意忌：疑忌、猜忌。
- 外寬內深：外表宽厚，内心深刻阴险。
- 郤：通「隙」，嫌隙、仇怨。
- 詳：通「佯」，假装。
- 陰報其禍：暗中报复他们，加祸于人。
- 董仲舒：西汉大儒，提倡独尊儒术。
- 膠西：胶西国，时胶西王刘端骄横，公孙弘建议把董仲舒派到胶西，欲借王手害之。
- 脫粟之飯：只脱去皮壳、不加精舂的糙米饭。
- 賔客：宾客。

### p7
**原文**：淮南、衡山謀反，治黨與方急。弘病甚，自以爲無功而封，位至丞相，宜佐明主填撫國家，使人由臣子之道。今諸侯有畔逆之計，此皆宰相奉職不稱，恐竊病死，無以塞責。⟦0⟧乃上書曰：「臣聞天下之通道五，所以行之者三。⟦1⟧曰君臣，父子，兄弟，夫婦，長幼之序，此五者天下之通道也。智，仁，勇，此三者天下之通德，所以行之者也。故曰『力行近乎仁，好問近乎智，知恥近乎勇』。知此三者，則知所以自治；知所以自治，然後知所以治人。天下未有不能自治而能治人者也，此百世不易之道也。今陛下躬行大孝，鑒三王，建周道，兼文武，厲賢予祿，⟦2⟧量能授官。今臣弘罷駑之質，無汗馬之勞，陛下過意擢臣弘卒伍之中，封爲列侯，致位三公。臣弘行能不足以稱，素有負薪之病，恐先狗馬填溝壑，終無以報德塞責。願歸侯印，乞骸骨，避賢者路。」天子報曰：「古者賞有功，襃有德，守成尚文，遭遇右武，⟦3⟧未有易此者也。朕宿昔庶幾獲承尊位，懼不能寧，惟所與共爲治者，君宜知之。蓋君子善善惡惡，君宜知之，君若謹行，常在朕躬。君不幸罹霜露之病，何恙不已，⟦4⟧⟦5⟧迺上書歸侯，乞骸骨，是章朕之不德也。今事少間，君其省思慮，一精神，輔以醫藥。」因賜告牛酒雜帛。居數月，病有瘳，視事。

**译文**：淮南王、衡山王谋反，朝廷惩治党羽正紧急。公孙弘病得很重，自认为无功而封侯，官至丞相，应当辅佐明主镇抚国家，使人遵守臣子之道。如今诸侯有叛逆的阴谋，这都是宰相不称职，恐怕自己默默病死，无法搪塞责任。于是上书说：「我听说天下的常道有五条，用来实行这五条的有三种美德。君臣、父子、兄弟、夫妇、长幼的次序，这五者是天下的常道。智、仁、勇，这三者是天下的常德，是用来实行常道的。所以说『努力行善近于仁，勤学好问近于智，知道羞耻近于勇』。知道这三者，就知道怎样修养自己；知道怎样修养自己，然后才知道怎样治理别人。天下没有不能自我修养却能治理别人的，这是百世不变的道理。如今陛下亲行大孝，以三王为鉴，建立周道，兼备文王武王之德，奖励贤才、给予俸禄，衡量才能授予官职。如今我公孙弘才能低劣，没有汗马功劳，陛下特意把我从行伍中提拔起来，封为列侯，位至三公。我的品行才能不能称职，平素又有病，恐怕先于狗马填入沟壑，最终无法报答恩德、搪塞责任。我希望交回侯印，请求辞官回家，给贤者让路。」天子答复说：「古代奖赏有功的人，褒扬有德的人，守住成业崇尚文德，遭遇祸乱崇尚武功，没有改变这个道理的。我从前侥幸继承尊位，恐惧不能安宁，想要和大家共同治理天下，你应该知道我的心意。君子是喜善憎恶的，你应该知道。你若谨慎行事，就常留在我身边。你不幸得了风寒小病，何愁不愈，竟上书交回侯印、请求辞官，这是显扬我的无德啊。如今事情稍少，你要少思虑，集中精神，辅以医药治疗。」于是赐予续假、牛酒和各种布帛。过了几个月，公孙弘病愈，上朝处理政事。

**译注**：
- 淮南、衡山：淮南王刘安、衡山王刘赐，武帝时谋反自杀。
- 黨與：同党、党羽。
- 填撫：镇抚；填通「镇」。
- 畔逆：叛逆；畔通「叛」。
- 塞責：搪塞责任。
- 通道：通行不变的道理。五伦三德说出自《礼记·中庸》。
- 力行近乎仁三句：语出《礼记·中庸》。
- 三王：夏禹、商汤、周文王武王。
- 周道：周朝的治道。
- 文武：周文王、周武王。
- 厲賢予祿：奖励贤才、给予俸禄；厲通「励」。
- 罷駑：疲弱无能的劣马，比喻才能低下；罷通「疲」。
- 汗馬之勞：战功。
- 卒伍：行伍、平民间。
- 負薪之病：自称有病的谦辞。
- 填溝壑：死的婉称，指死而弃于沟壑。
- 乞骸骨：古代官员请求退休的婉辞，意为使骸骨归葬故乡。
- 襃：褒扬。
- 守成尚文，遭遇右武：守成之时崇尚文治，祸乱之际重视武功。右，崇尚。
- 庶幾：侥幸。
- 善善惡惡：喜善憎恶。前「善」「恶」为动词。
- 罹霜露之病：遭受风寒小病。
- 何恙不已：什么病不好，意为小病何愁不愈。
- 章：彰显、显扬。
- 少間：稍停息。
- 一精神：集中精神；一通「壹」。
- 賜告：准予休假。
- 瘳：病愈。
- 視事：处理政事。

### p8
**原文**：元狩二年，弘病，竟以丞相終。⟦0⟧⟦1⟧子度嗣爲平津侯。度爲山陽太守十餘歲，坐法失侯。⟦2⟧

**原文**：太皇太后詔大司徒大司空：⟦0⟧⟦1⟧「蓋聞治國之道，富民爲始；富民之要，在於節儉。孝經曰『安上治民，莫善於禮』。『禮，與奢也寧儉』。昔者管仲相齊桓，霸諸侯，有九合一匡之功，而仲尼謂之不知禮，以其奢泰侈擬於君故也。夏禹卑宮室，惡衣服，後聖不循。由此言之，治之盛也，德優矣，莫高於儉。儉化俗民，則尊卑之序得，而骨肉之恩親，爭訟之原息。斯乃家給人足，刑錯之本也歟？可不務哉！夫三公者，百寮之率，萬民之表也。未有樹直表而得曲影者也。孔子不云乎，『子率而正，孰敢不正』。『舉善而教不能則勸』。維漢興以來，股肱宰臣身行儉約，輕財重義，較然著明，⟦2⟧未有若效丞相平津侯公孫弘者也。位在丞相而爲布被，脫粟之飯，不過一肉。故人所善賔客皆分奉祿以給之，無有所餘。誠內自克約而外從制。汲黯詰之，乃聞于朝，此可謂減於制度⟦3⟧而可施行者也。德優則行，否則止，與內奢泰而外爲詭服以釣虛譽者殊科。以病乞骸骨，孝武皇帝即制曰『賞有功，襃有德，善善惡惡，君宜知之。其省思慮，存精神，輔以醫藥』。賜告治病，牛酒雜帛。居數月，有瘳，視事。至元狩二年，竟以善終至相位。夫知臣莫若君，此其效也。弘子度嗣爵，後爲山陽太守，坐法失侯。夫表德章義，所以率俗厲化，聖王之制，不易之道也。其賜弘後子孫之次當爲後者爵關內侯，食邑三百戶，徵詣公車，上名尚書，朕親臨拜焉。」

**原文**：班固稱曰：公孫弘、卜式、兒寬皆以鴻漸之翼困於燕雀，⟦0⟧⟦1⟧遠迹羊豕之間，⟦2⟧⟦3⟧非遇其時，焉能致此位乎？是時漢興六十餘載，海內乂安，⟦4⟧府庫充實，而四夷未賔，制度多闕，上方欲用文武，求之如弗及。始以蒲輪迎枚生，⟦5⟧見主父而歎息。⟦6⟧羣臣慕嚮，異人並出。卜式試於芻牧，弘羊擢於賈豎，衞青奮於奴僕，日磾出於降虜，斯亦曩時版築飯牛之明矣。漢之得人，於茲爲盛。儒雅則公孫弘、董仲舒、兒寬，篤行則石建、石慶，質直則汲黯、卜式，推賢則韓安國、鄭當時，定令則趙禹、張湯，文章則司馬遷、相如，滑稽則東方朔、枚臯，應對則嚴助、朱買臣，歷數則唐都、落下閎，恊律則李延年，運籌則桑弘羊，奉使則張騫、蘇武，將帥則衞青、霍去病，受遺則霍光、金日磾。其餘不可勝紀。是以興造功業，制度遺文，後世莫及。孝宣承統，纂脩洪業，亦講論六蓺，招選茂異，而蕭望之、梁丘賀、夏侯勝、韋玄成、嚴彭祖、尹更始以儒術進，劉向、王褒以文章顯。將相則張安世、趙充國、魏相、邴吉、于定國、杜延年，治民則黃霸、王成、龔遂、鄭弘、邵信臣、韓延壽、尹翁歸、趙廣漢之屬，皆有功迹見述於後。累其名臣，亦其次也。

**译文**：班固评论说：公孙弘、卜式、儿宽都有鸿鹄高飞的才干，却被燕雀般的俗人所困，远在放猪牧羊之间隐迹，不是遇到那个时代，怎能得到这样的高位呢？那时汉朝建立六十多年，海内安定，府库充实，而四夷尚未宾服，制度多有缺漏，皇上正想任用文武人才，求之好像来不及。开始用安车蒲轮迎接枚生，见到主父偃而为之叹息相见恨晚。群臣仰慕向风，异人奇才一起涌出。卜式从牧羊人中被举用，桑弘羊从商人中被提拔，卫青从奴仆中奋起，金日磾从降虏中选出，这也如同古时傅说版筑、宁戚饭牛那样的明君举贤故事啊。汉朝得到人才，在武帝时最盛。儒雅有公孙弘、董仲舒、儿宽，笃行有石建、石庆，质直有汲黯、卜式，推贤有韩安国、郑当时，制定法令有赵禹、张汤，文章有司马迁、司马相如，滑稽有东方朔、枚皋，应对有严助、朱买臣，历数有唐都、落下闳，协律有李延年，运筹有桑弘羊，奉使有张骞、苏武，将帅有卫青、霍去病，受遗诏辅政有霍光、金日磾。其余的不可胜记。所以这一时期兴办的功业、制度、文章，后世都赶不上。孝宣帝继承大统，继续修治大业，也讲论六艺，招选茂才异等，萧望之、梁丘贺、夏侯胜、韦玄成、严彭祖、尹更始以儒术进用，刘向、王褒以文章显名。将相位则张安世、赵充国、魏相、邴吉、于定国、杜延年，治民则黄霸、王成、龚遂、郑弘、邵信臣、韩延寿、尹翁归、赵广汉等人，都有功迹被后世称述。考察宣帝时的名臣，也是武帝之后的次盛之世了。

**译注**：

- 卜式：西汉武帝时人，以牧羊出身，输财助边，官至御史大夫。
- 兒寬：即倪宽，西汉经学家，官至御史大夫。
- 鴻漸之翼：鸿雁高飞的翅膀，比喻大才。鸿渐，语出《易·渐》「鸿渐于陆」。

- 遠迹羊豕之間：指公孙弘牧猪、卜式牧羊、儿宽读书耕作等出身微贱事。
- 乂安：安定太平。乂（yì），治理。
- 未賔：未宾服归降。

- 芻牧：割草放牧，指卜式牧羊事。
- 弘羊擢於賈豎：桑弘羊从商人子弟中被提拔。贾竖，对商人的贱称。

### p30
**原文**：索隱述贊曰：平津巨儒，晚年始遇。外示寬儉，內懷嫉妬。寵備榮爵，身受肺腑。主父推恩，觀時設度。生食五鼎，死非時蠹。

**译文**：
【索隐述赞】
平津巨儒，晚年始遇。外示宽俭，内怀嫉妒。宠备荣爵，身受肺腑。主父推恩，观时设度。生食五鼎，死非时蠹。

**语词典释**：
- **平津巨儒，晚年始遇**：公孙弘为平津侯一代大儒，六十岁始被举、晚年才遇时得用。
- **外示寬儉，內懷嫉妬**：他外表装出宽厚节俭的样子，内心却怀藏嫉妒忌恨，指其外宽内深、阴报祸怨。
- **寵備榮爵，身受肺腑**：荣宠备至、封侯拜相，身受皇帝肺腑之亲的信任。肺腑，指皇帝心腹之臣。
- **主父推恩，觀時設度**：主父偃献推恩之策，审时度势设立制度。
- **生食五鼎，死非時蠹**：活着时列五鼎而食，富贵至极，死却因非其时而死，为世所蠹（坏），指其横遭族灭。時蠹，谓为当时刑律所蠹害。
