# 殷本纪第三·白话定稿

## 原文与译文

## p0
**原文**：
殷契，⟦0⟧⟦1⟧母曰簡狄，⟦2⟧有娀氏之女，⟦3⟧⟦4⟧爲帝嚳次妃。三人行浴，見玄鳥墮其卵，簡狄取吞之，因孕生契。⟦5⟧契長而佐禹治水有功。帝舜乃命契曰：「百姓不親，五品不訓，汝爲司徒而敬敷五教，五教在寬。」封于商，⟦6⟧⟦7⟧⟦8⟧賜姓子氏。⟦9⟧⟦10⟧契興於唐、虞、大禹之際，功業著於百姓，百姓以平。

**译文**：
殷人的始祖叫契，他的母亲名叫简狄，是有娀氏的女儿，也是帝喾的第二位妃子。有一次，简狄和另外两人一起到野外洗浴，看见一只玄鸟（燕子）落下一枚蛋，简狄捡起来吞了下去，于是怀孕生下了契。契长大后辅佐大禹治水，立下了功劳。帝舜于是任命契说：「现在百姓之间不相亲睦，五种人伦关系也不和顺，你去担任司徒，要恭谨地传布五伦教化，推行五教的关键在于宽厚。」于是把契封在商地，赐姓子氏。契在唐尧、虞舜、大禹的时代兴起，他的功业昭著于百姓之中，百姓因此生活安定。

**译注**：
1. 玄鳥：黑色的鸟，即燕子。《诗经·商颂·玄鸟》开篇即云「天命玄鸟，降而生商」，简狄吞玄鸟卵生契是商族最著名的起源神话，反映了商族的鸟图腾崇拜。
2. 五品：也称五伦，指父子、君臣、夫妇、长幼、朋友五种基本人伦关系。五教：针对五伦的五种教化，即父义、母慈、兄友、弟恭、子孝。
3. 司徒：上古掌教化之官。敬敷：恭敬地传布。商：商族最早的封地，在今河南商丘一带。
4. 百姓以平：百姓因此太平安定。平，平安、安定。

## p1
**原文**：
契卒，子昭明立。昭明卒，子相土立。⟦0⟧⟦1⟧⟦2⟧相土卒，子昌若立。昌若卒，子曹圉立。⟦3⟧  曹圉卒，⟦4⟧子冥立。⟦5⟧⟦6⟧冥卒，子振立。⟦7⟧振卒，子微立。⟦8⟧微卒，子報丁立。報丁卒，子報乙立。報乙卒，子報丙立。報丙卒，子主壬立。主壬卒，子主癸立。主癸卒，子天乙立，是爲成湯。⟦9⟧⟦10⟧

**译文**：
契去世后，他的儿子昭明继位。昭明去世，儿子相土继位。相土去世，儿子昌若继位。昌若去世，儿子曹圉继位。曹圉去世，儿子冥继位。冥去世，儿子振继位。振去世，儿子微继位。微去世，儿子报丁继位。报丁去世，儿子报乙继位。报乙去世，儿子报丙继位。报丙去世，儿子主壬继位。主壬去世，儿子主癸继位。主癸去世，儿子天乙继位，这就是成汤。

**译注**：
1. 本段记载自契至成汤共十四世商族先公的世系传承。「振」即甲骨文和古文献中的王亥，是商族先公中功绩显著的一位，以「服牛」（驯养牛）闻名，被商人尊为「高祖王亥」；「微」即上甲微，是商代周祭制度中第一个被隆重祭祀的先公，在商族发展史上地位重要。报丁、报乙、报丙合称「三报」，主壬、主癸合称「二主」，他们的名号用天干命名，反映了商代已形成较为成熟的日名制度。
2. 王国维《殷卜辞中所见先公先王考》首次以甲骨文证实了《史记》所载商代先公先王世系的基本可信，是甲骨文证史的经典成果。

## p2
**原文**：
成湯，自契至湯八遷。⟦0⟧湯始居亳，⟦1⟧⟦2⟧從先王居，⟦3⟧⟦4⟧作帝誥。⟦5⟧

**译文**：
成汤在位时，从始祖契到成汤一共迁都八次。汤开始在亳建都，这是回到先王帝喾的旧都居住，于是作《帝诰》篇以告慰先王。

**译注**：
1. 八遷：商族在建立王朝前的八次迁徙，具体地点历代学者考证不一，王国维有详细考证。商人屡迁可能与游农、水患及政治需要有关。
2. 亳（bó）：商汤灭夏前的都城，此指南亳（今河南商丘东南），汤灭夏后又建西亳（今河南偃师西）。從先王居：指亳为帝�旧都，汤迁回亳有追承先王正统之意。
3. 《帝誥》：《尚书》篇名，今已亡佚，内容应为迁都告庙之辞。

## p3
**原文**：
湯征諸侯。⟦0⟧葛伯不祀，湯始伐之。⟦1⟧湯曰：「予有言：人視水見形，視民知治不。」伊尹曰：「明哉！言能聽，道乃進。君國子民，爲善者皆在王官。勉哉，勉哉！」湯曰：「汝不能敬命，予大罰殛之，無有攸赦。」作湯征。

**译文**：
成汤开始征伐不义的诸侯。葛伯不祭祀鬼神，成汤首先讨伐他。汤说：「我有句话：人往水面照就能看见自己的形貌，观察民众的状况就知道国家治理得好不好。」伊尹说：「英明啊！能听得进善言，道德才会进步。治理国家、抚育人民，要把所有行善的人都选拔到朝廷任职。努力吧，努力吧！」汤又说：「你们如果不能恭敬地遵从天命，我就要对你们加以重罚，绝不宽赦。」于是作《汤征》篇记载此事。

**译注**：
1. 葛伯：葛国国君。葛国在今河南宁陵北，是商的近邻小国。葛伯不祀是汤灭夏战争的开端，《孟子·滕文公下》详载汤使亳众助葛伯耕田、葛伯杀送食童子之事，所谓「汤始征，自葛载」。
2. 治不：即「治否」，治理得好不好。「不」通「否」。
3. 君國子民：统治国家、爱护人民。君、子皆为动词，意为君临、像爱护子女一样养护。
4. 殛（jí）：诛杀、惩罚。攸赦：有所赦免。《湯征》：《尚书》篇名，今亡佚。

## p4
**原文**：
伊尹名阿衡。⟦0⟧阿衡欲奸湯而無由，乃爲有莘氏媵臣，⟦1⟧⟦2⟧負鼎俎，以滋味說湯，致于王道。或曰，伊尹處士，湯使人聘迎之，五反然後肯往從湯，言素王及九主之事。⟦3⟧⟦4⟧湯舉任以國政。伊尹去湯適夏。旣醜有夏，復歸于亳。入自北門，遇女鳩、女房，作女鳩女房。⟦5⟧

**译文**：
伊尹名叫阿衡。阿衡想求见成汤却没有门路，就自愿做了有莘氏陪嫁的奴仆，背着鼎和俎等烹饪器具，用烹调五味的道理游说汤，最终引导汤成就王道。也有人说，伊尹本是隐居不仕的处士，成汤派人聘请迎接他，往返了五次他才肯出山追随汤，向汤讲论素王之道和九类君主的政事得失。汤提拔他执掌国政。伊尹曾一度离开成汤到夏桀那里任职。因为觉得夏桀政治丑恶，又回到亳都。他从北门进城时，遇到了汤的贤臣女鸠和女房，于是作《女鸠》《女房》两篇，表明离开夏桀复归成汤的心志。

**译注**：
1. 阿衡：一说为伊尹之名，一说为其官号（相当于后世的宰相）。奸（gān）：通「干」，求见。
2. 有莘（shēn）氏：上古部落名，姒姓，地在今山东曹县北。媵（yìng）臣：古代贵族嫁女时陪嫁的奴仆。
3. 鼎俎（zǔ）：鼎为烹煮器具，俎为切肉砧板，均为厨事之具。「以滋味说汤」是说伊尹借烹饪调味之理喻治国之道，《吕氏春秋·本味篇》保存了伊尹以至味说汤的详细记载，后世遂以「负鼎」作为贤才干主、出身微贱的典故。
4. 處士：隐居不仕的有才德之人。五反：往返五次。素王：有王者之德而未居王位之人，一说指上古帝王。九主：据《史记集解》引刘向《别录》，指三皇、五帝及夏禹共九类君主。
5. 醜有夏：认为夏政丑恶，即厌弃夏桀。女鳩、女房：成汤的两位贤臣。《女鳩》《女房》均为《尚书》篇名，今已亡佚。

## p5
**原文**：
湯出，見野張網四面，祝曰：「自天下四方皆入吾網。」湯曰：「嘻，盡之矣！」乃去其三面，祝曰：「欲左，左。欲右，右。不用命，乃入吾網。」諸侯聞之，曰：「湯德至矣，及禽獸。」

**译文**：
有一次成汤外出，看见野外有人四面都张起了罗网，张网的人祷告说：「从天上地下四方来的，都进到我的网里来。」汤说：「唉，这样就一网打尽了！」于是下令撤掉其中三面的网，并教张网人改祝词说：「想往左走的就往左走，想往右逃的就往右逃。不听从命令的，才进我的网。」各国诸侯听说这件事，都说：「汤的恩德真是到了极点，连禽兽都受到了他的恩惠。」

**译注**：
1. 此即「网开三面」（后世多作「网开一面」）的典故。汤去三面之网，示其仁德好生，以此感化诸侯，故诸侯归心。祝：祷告、祝祷。
2. 不用命：不听从教令，指自投罗网者。「湯德至矣，及禽獸」：汤的恩德已臻极致，连禽兽都能蒙其恩泽。

## p6
**原文**：
當是時，夏桀爲虐政淫荒，而諸侯昆吾氏爲亂。⟦0⟧湯乃興師率諸侯，伊尹從湯，湯自把鉞以伐昆吾，遂伐桀。湯曰：「格女衆庶，來，女悉聽朕言。匪台小子敢行舉亂，⟦1⟧有夏多罪，予維聞女衆言，夏氏有罪。予畏上帝，不敢不正。⟦2⟧今夏多罪，天命殛之。今女有衆，女曰『我君不恤我衆，舍我嗇事而割政』。⟦3⟧女其曰『有罪，其柰何』？夏王率止衆力，率奪夏國。⟦4⟧有衆率怠不和，⟦5⟧曰『是日何時喪？予與女皆亡』！⟦6⟧夏德若茲，今朕必往。爾尚及予一人致天之罰，予其大理女。⟦7⟧女毋不信，朕不食言。⟦8⟧女不從誓言，予則帑僇女，無有攸赦。」以告令師，作湯誓。於是湯曰「吾甚武」，號曰武王。⟦9⟧

**译文**：
就在这个时候，夏桀施行暴政、荒淫无度，而诸侯中的昆吾氏也趁机作乱。成汤于是兴兵率领诸侯出征，伊尹随军辅佐，汤亲自手持大钺，先讨伐了昆吾，接着便挥师讨伐夏桀。汤在誓师大会上说：「过来，你们这些人，都来听我的话。不是我小子敢兴兵作乱，而是因为夏桀犯下了太多罪行，我也听到你们大家都说夏氏有罪。我敬畏上帝，不敢不去征讨他。现在夏桀罪恶滔天，上天命令我诛灭他。如今你们众人中有人说『我们的君主不体恤我们，让我们荒废农活，却去推行这种残害民力的暴政』。你们或许会问『夏桀有罪，又能把他怎么样呢？』夏王耗尽了民力，盘剥夏国的百姓。夏国的民众全都懈怠涣散，不与他同心，说『你这个太阳什么时候才灭亡？我宁愿和你一起去死！』夏桀的德行败坏到这种地步，如今我一定要前去讨伐他。你们只要辅佐我，奉行上天对夏桀的惩罚，我就会重重地赏赐你们。你们不要不相信，我绝不会说话不算数。如果你们不听从我的誓言，我就要罚你们和你们的妻室子女为奴婢，甚至诛杀你们，绝不宽赦。」汤把这番话通告全军，作《汤誓》篇。当时汤说「我很勇武」，因此自号武王。

**译注**：
1. 夏桀：夏朝末代君主，名履癸，是历史上著名的暴君。昆吾氏：夏的同姓诸侯，己姓，为夏伯，其地在今河南濮阳一带，是当时东方较有势力的方国，为桀之党羽。
2. 鉞（yuè）：大斧，古代的一种兵器，也是军事统帅权的象征，后世有「假黄钺」作为天子赐给重臣征伐大权的最高礼遇。
3. 格：来。女（rǔ）：通「汝」，你、你们。匪：非，不是。台（yí）：我，为汤自称。小子：先秦时帝王自谦之称。
4. 正：通「征」，征讨。恤：体恤、怜悯。嗇事：农事，「嗇」同「穑」，收割庄稼，泛指农业生产。割政：害民之政，「割」通「害」。
5. 率：语助词，一说「尽」。止衆力：耗尽民力。率怠不和：全都懈怠不与夏桀同心。
6. 是日何時喪：这个太阳什么时候灭亡。相传夏桀曾自比太阳，说「天之有日，犹吾之有民，日有亡哉？日亡吾亦亡矣」，故民众以此诅咒他。「时日曷丧，予及汝皆亡」成为后世反抗暴君的著名典故。女（rǔ）：你，指夏桀。
7. 予一人：商周时天子自称，为上古帝王专用之谦称。理：通「釐」，赏赐。食言：违背诺言，即说话不算数。
8. 帑僇（nú lù）：帑通「孥」，指将罪人的妻室子女罚为奴婢；僇通「戮」，杀戮。
9. 《湯誓》：《尚书》中的一篇，今存，记载汤伐桀时的誓师辞，与本篇文句大致相同。吾甚武：汤自认为勇武，故号武王。此武王为成汤自号，非后世周武王姬发。

## p7
**原文**：
桀敗於有娀之虛，桀犇於鳴條，⟦0⟧夏師敗績。湯遂伐三㚇，俘厥寶玉，⟦1⟧⟦2⟧義伯、仲伯作典寶。⟦3⟧湯旣勝夏，欲遷其社，不可，⟦4⟧作夏社。⟦5⟧伊尹報。⟦6⟧於是諸侯必服，湯乃踐天子位，平定海內。

**译文**：
夏桀在有娀氏的旧地被打败，逃奔到鸣条，夏军全军溃败。成汤接着讨伐三㚇国，缴获了他们珍藏的宝玉，义伯、仲伯二人因此作《典宝》篇，记载宝玉的来历和得宝之事。汤战胜夏朝之后，想要迁移夏的社神神位，却觉得不能迁，于是作《夏社》篇说明社不可迁的道理。伊尹向诸侯通报了伐夏胜利的消息。于是诸侯全都归服，汤就登上天子之位，平定了天下。

**译注**：
1. 有娀之虛：有娀氏部落的旧居地，在今山西永济一带。「虛」通「墟」，指故城旧址。犇：「奔」的古字。鳴條：古地名，在今山西运城安邑镇北（一说在河南封丘东），鸣条之战是商汤灭夏的决定性战役，夏桀主力在此被击溃。
2. 敗績：军队完全崩溃大败。三㚇（zōng）：古国名，在今山东定陶东北，为夏桀的盟国，桀战败后曾逃奔于此。俘厥寶玉：缴获三㚇的宝玉。
3. 義伯、仲伯：成汤的两位大臣。《典寶》：《尚书》篇名，今亡佚，内容为记载所得宝玉之事。
4. 遷其社：社是土神，也是国家政权的象征，灭国后通常迁走其社以表示改朝换代。不可：指夏社不可迁，一说因为社为后土之神，「社者，土地之主，不可更替」；一说因未找到合适的替代者，终未迁。
5. 《夏社》：《尚书》篇名，今亡佚。伊尹報：指伊尹作《咸有一德》向天下通报伐夏成功、改朝换代的消息。一說「報」为报政，即还师后向先王报功。
6. 踐天子位：登上帝位。商朝是中国历史上第二个王朝，约公元前1600年由成汤建立。

## p8
**原文**：
湯歸至于泰卷陶，⟦0⟧⟦1⟧⟦2⟧中𤳹作誥。⟦3⟧⟦4⟧旣絀夏命，⟦5⟧還亳，作湯誥：「維三月，王自至於東郊。告諸侯羣后：『毋不有功於民，勤力迺事。予乃大罰殛女，毋予怨。』曰：『古禹、臯陶久勞于外，其有功乎民，民乃有安。東爲江，北爲濟，西爲河，南爲淮，四瀆已脩，萬民乃有居。后稷降播，農殖百穀。三公咸有功于民，故后有立。⟦6⟧⟦7⟧昔蚩尤與其大夫作亂百姓，帝乃弗予，⟦8⟧有狀。⟦9⟧先王言不可不勉。』⟦10⟧曰：『不道，毋之在國，⟦11⟧⟦12⟧女毋我怨。』」以令諸侯。伊尹作咸有一德，⟦13⟧⟦14⟧咎單作明居。⟦15⟧

**译文**：

**译注**：
1. 泰卷陶：即大坰（jiōng），古地名，在今山东定陶。中𤳹（huǐ）：即仲虺（huǐ），成汤时的左相（伊尹为右相），与伊尹共同辅佐汤定天下。
2. 絀（chù）：通「黜」，废除、废止。夏命：夏朝的国命，即夏朝享有的统治天下的天命。
3. 《湯誥》：《尚书》篇名，今文《尚书》中的《汤诰》为东晋梅赜所献古文，内容与此处引文略有差异，学者多疑为伪作。羣后：众位诸侯。后，君主。
4. 臯陶（gāo yáo）：舜时掌刑狱之臣，为禹的主要辅佐者。四瀆（dú）：古人对四条独流入海的大河的总称，即长江、黄河、淮河、济水。修：修治、疏通。
5. 后稷：周族的始祖，名弃，为舜时的农官，教民播种百谷，被后世祀为农神。農殖：种植。
6. 三公：指禹、皋陶、后稷三人。故后有立：所以他们的后代得以建立国家——禹之后为夏朝，皋陶之后封于英、六，后稷之后为周朝。
7. 蚩（chī）尤：上古九黎族部落首领，相传与黄帝战于涿鹿，兵败被杀。弗予：不保佑、不赞许。予，赞许。有狀：有事实根据，明明白白。
8. 不道：不行道义。毋之在國：不要让他在国中执政，即剥夺其君位。
9. 咎（gāo）單：成汤时的贤臣，司空之官。《咸有一德》：《尚书》篇名，今存古文，记伊尹还政后陈戒太甲之言。《明居》：《尚书》篇名，今亡佚，记咎单明居民之法。

1. 怨望：怨恨。「望」也是怨恨的意思。畔：通「叛」，背叛。刑辟：刑法。炮格之法：即炮烙之刑，相传是在铜柱上涂油，下面点燃炭火，让有罪的人在铜柱上行走，坠入炭火中烧死，是商纣所设著名酷刑。
2. 三公：朝廷中地位最高的三位辅政大臣。西伯昌：即周文王姬昌，当时为西方诸侯之长，故称西伯。九侯：又作「鬼侯」，商代诸侯。鄂侯：又作「邘侯」，商代诸侯。
3. 憙（xǐ）：同「喜」，喜欢。醢（hǎi）：古代酷刑，把人剁成肉酱。脯（fǔ）：古代酷刑，把人杀死后做成肉干。
4. 崇侯虎：崇国（在今河南嵩县北）国君，名虎，是商纣的佞臣，历史上第一个有记载的告密者。羑（yǒu）里：古地名，在今河南汤阴北，是商代著名的国家监狱，相传周文王在此被囚七年，推演《周易》。
5. 閎夭：周文王的著名贤臣，与散宜生、太颠等同为「文王四友」之一。洛西之地：洛水以西的土地，在今陕西洛河一带。
6. 弓矢斧鉞：天子授予专征伐大权的象征物。鉞（yuè），大斧，代表军权。費中：又作费仲，纣之佞臣，以贪财好利著称。惡來：纣之佞臣，以勇力事纣，善于进谗言诋毁诸侯，后被周武王所杀，其后人后来建立了秦国。

**译文**：

2. 飢國：即耆国，又作「黎」，在今山西长治西南，是商西部重要属国。周文王灭耆（戡黎）是周人灭商的重要战略步骤。祖伊：商纣时贤臣，祖己的后代。
3. 訖（qì）：终止、断绝。假人元龜：借助于灵龟进行占卜。假，借；元龟，大龟，上古时用于占卜的国宝。
4. 相（xiàng）：保佑、帮助。不虞知天性：不揣度、不了解上天的本性。不迪率典：不遵循法典常规。迪，遵循；率，循。
5. 曷（hé）：何，为什么。大命：指改朝换代、承受天命的新君主（暗指周）。反：通「返」。
6. 盟津：即孟津，古黄河渡口，在今河南孟津东北。武王会八百诸侯于孟津是灭商前的一次大规模军事演习和政治检阅，史称「孟津之会」或「盟津观兵」。武王认为灭商时机尚未完全成熟，所以班师西归。

**译文**：
