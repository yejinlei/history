# 中国历史本体论 · History Ontology

> 以本体论方法重构中国历史知识体系，鉴往知来，稽古揆今。

## 项目简介

本项目是一个面向中国历史的领域本体（Domain Ontology）工程，参考现代知识工程规范，融合中国传统史学义理与近现代史学研究范式，采用**「四轴 × 七层」正交矩阵架构**，严格区分 TBox（术语盒）与 ABox（断言盒），为中国历史知识图谱、智能问答、可视化分析提供统一的语义基础。

在线访问：[https://yejinlei.github.io/history/](https://yejinlei.github.io/history/)

## 本体架构

### 四轴正交维度
- **A1 体裁分类轴**：史书体裁与分类体系（正史、编年、纪事本末、政书、方志等）
- **A2 史实内容轴**：时间·地理·制度·社会·经济·文化
- **A3 人物主体轴**：帝王·官僚·士人·史家·庶民
- **A4 时序缘起轴**：事件·变革·因果脉络

### 七层抽象体系
| 层级 | 名称 | 内容 |
|---|---|---|
| L0 | 元模型层 | Entity/Axis/Layer/Class/Property/Individual，本体结构规范 |
| L1 | 史观本体层 | 唯物史观、循环史观、进步史观、历史演化规律 |
| L2 | 史学范畴层 | 史学方法（考据、阶级分析、计量）、历史核心概念 |
| L3 | 学派分期层 | 史学流派、历史分期体系、学脉传承 |
| L4 | 文献载体层 | 史书体裁、文本结构（Book→Volume→Chapter→Section）、作者注家 |
| L5 | 人物传承层 | 历史人物、典章制度、事件地理 |
| L6 | 记忆书写外延层 | 版本流传、历史记忆、文化遗产、人物形象演变 |

## 核心内容覆盖

### 二十四史单本本体
覆盖从《史记》到《明史》共24部正史，总计3229卷，约4000万字，每部史书作为 `hi:StandardHistory` 的独立实例：
- 史记、汉书、后汉书、三国志
- 晋书、宋书、南齐书、梁书、陈书、魏书、北齐书、周书
- 隋书、南史、北史
- 旧唐书、新唐书、旧五代史、新五代史
- 宋史、辽史、金史、元史、明史

### 中国通史体系
从先秦到近现代贯通叙事，整合多元体裁通史著作：
- 纪传体通史：《史记》
- 编年体通史：《资治通鉴》
- 典制体通史："三通"（《通典》《通志》《文献通考》）
- 纪事本末体：《通鉴纪事本末》
- 近现代通史：吕思勉《白话本国史》、钱穆《国史大纲》等

### 现代史学四大家
涵盖严耕望所推"现代史学四大家"：
- **吕思勉**（1884-1957）：通史贯通，社会科学立场
- **陈垣**（1880-1971）：考据工具，宗教史与元史
- **陈寅恪**（1890-1969）：中古专题，以诗证史与中外交流
- **钱穆**（1895-1990）：文化本位，学术思想史

## 落地路线（M1-M5）
1. **M1 骨架定版**：完成四轴×七层架构、类体系、属性、关系谓词定义 ✓
2. **M2 史观·人物层填充**：史观方法、核心人物、学派体系三元组入库
3. **M3 文献载体层挂接**：二十四史全本卷次结构挂接，其他典籍目录入图
4. **M4 事件·制度层填充**：重大历史事件、典章制度、历史地理实体入库
5. **M5 应用层**：知识图谱可视化、全文检索、智能问答、注疏批注系统
