# 白话重译作业规范（对标核验工作流）

> 适用：抓取白话本已有、尚未自译的篇目（当前 67 篇列传）。
> 原则：**抓取白话仅作参照，入库文字一律回到原典逐句撰写。**

---

## 一、流水线（每篇五道工序，单元互相分离）

```
① 对标核验（核验单元）  → proofread/<篇>-对标核验.md
② 重译初稿（翻译单元）  → translations/白话-初稿-<篇>.md
③ 互校（独立校验单元）  → proofread/<篇>-翻译校验.md
④ 定稿（合成单元）      → translations/白话-定稿-<篇>.md
⑤ 本体/增强/标注 + 上库 → ontology/、git commit
```

- **③ 互校单元必须与 ② 翻译单元上下文分离**：互校方不得沿用翻译方的结论，须独立回原典逐段复看。
- 做一批上库一批。

## 二、输入

| 材料 | 路径 |
|---|---|
| 原典正文（含 ⟦N⟧ 注疏锚点，永不改动） | `data/books/shiji/text/shiji-<繁体篇名>.json` |
| 三家注（裴骃集解／司马贞索隐／张守节正义） | `data/books/shiji/annotations/shiji-<繁体篇名>.json` |
| 抓取白话参照本 | `reference/baihua_shiji/<简体篇名>.txt` |
| 格式样例 | `translations/白话-定稿-伯夷列传.md`、`translations/白话-初稿-管晏列传.md` |
| 白话本已知缺陷 | `reference/对标核验/白话本质量体检报告.md` |

## 三、对标核验报告（①）必查项

逐段把抓取白话与原典比对，列出：

1. **衍文**（尤其「史记」二字——已知 468 处污染）；
2. **错字 / 拆字 / 音讹**（如《胠箧》误作《月去箧》、太宰嚭误作「伯喜否」）；
3. **脱漏**（漏句、漏词，如漏「字伯陽」）；
4. **增字增义**（白话擅增，如「阿、甄」增作「东阿、甄城」）；
5. **误译 / 曲解**（地名、人名、制度、典故出错）；
6. **缩译合并**（白话压缩原文，导致段句无法对应）；
7. **缺注**（白话本基本无注）。

报告须**逐条给出**：抓取本原文 → 原典对应句 → 问题定性 → 重译处置。

## 四、重译（②）规范

- **逐段对应**：段号与原典 `p0…pN` 一一对应，标题格式 `## 第N段（底本 pM）——<小标题>`。
- **紧扣原典**：以原典为准绳，不照抄抓取白话；文意、语序、称谓一律回到原典。
- **随文出注**：专名（人物／地名／职官）、古语、名物、典制随文以〔〕出注；三家注精要择要吸收。
- **保留语气**：太史公的疑辞（若、儻、岂）、议论、引用（《诗》《书》《易》等）以引语出之，不作史迁直陈。
- **述赞**：依「保留原文＋语词典释」体例，不逐句硬译。
- **不复现抓取本缺陷**：衍文、错字、残缺一律回改。

## 五、质量红线

- 原典正文**一字不改**（校勘异文只入校勘记）。
- 无证据不入本体：每个实体须携带 `evidence` 段号。
- **段落对齐**：译文段落数须与原典段落数**完全一致**，段段一一对应（第N段 ↔ 底本 p(N-1)），不得脱漏、错位、合并。
- 命名：以项目现有命名为准（`白话-初稿-<篇>.md` / `白话-定稿-<篇>.md`）。

> 注：译文是白话，不与文言原典「逐字相等」；机器校验的判据是**段数一致 + 段号对应**，引用原典文句处再核对是否与底本相符。
