# 抓取白话本《白话史记》质量体检报告

> 体检对象：gxdq.com《白话二十四》之《白话史记》，111 个实际篇目文件（另有 3 个目录页）。
> 体检目的：判定该白话本能否直接采信 / 作为底稿，还是只能作参照。
> 结论：**只能作参照，不能作数据源**——文本存在系统性污染与残缺，逐篇均须对标原典核验并按需重译。

---

## 一、硬伤：系统性衍文「史记」

抓取文本中「史记」二字被**机械插入**到句子中间，共出现 **468 处、覆盖全部 114 个文件**，无一文件幸免。这显然是抓取源或中间环节的模板替换污染，绝非原文可有。

| 出错句（抓取本） | 对应原典 | 性质 |
|---|---|---|
| 于是**史记**阖庐答应他 | 于是許之 | 衍文 |
| 都出自管仲**史记**的谋划 | （皆出於管仲之謀） | 衍文 |
| 李假在**史记**汉文帝朝任职做官 | 假事漢孝文 | 衍文 |
| **史记**万石君迁居到陵里 | 萬石君徙居陵里 | 衍文 |
| 直**史记**不疑向他道歉并承认 | 直不疑谢之 | 衍文 |
| 左**史记**右人答道 | 左右人對曰 | 衍文 |
| 洁**史记**净虔诚以祭祀 | （絜淨） | 衍文 |
| 天下人都**史记**心悦诚服 | 天下咸服 | 衍文 |
| 大**史记**夫 | 大夫 | 衍文 |
| 太宰伯喜否当权 | 太宰嚭 | 音讹 |

> 处理方法：此类污染点全部不可采信，重译须**一律以原典为准**回改。

## 二、错字、拆字与残缺

- **拆字**：老子韩非列传「《**月去箧**》」——当作《胠箧》，把「胠」拆成「月＋去」。
- **音讹**：把「太宰嚭」写作「伯喜否」。
- **残缺**：老子韩非列传「李解任胶西王**刘..**的太傅」——人名残缺（当作「刘卬」）。
- **增字**：司马穰苴列传「**东**阿、甄城」——原典作「阿、甄」，白话擅增「东」字。

## 三、漏译

- 老子韩非列传首句漏「**字伯陽**」：白话只作「名耳，字聃」，脱去「字伯阳」三字（原典「姓李氏，名耳，字伯陽，謚曰聃」）。

## 四、体例：通俗缩译，无法逐句对齐

- 白话本属**通俗缩译本**：大意尚存，但细节大量压缩、合并，**与出版本段句无法一一对应**，不能作为逐句锚点的数据底本。
- 例：老子韩非列传 p1「孔子適周，將問禮於老子」在抓取本中被并入前段、语序打散。

## 五、批注：基本缺位

- 白话本**基本无注**，偶有零星夹注，远不敷用。
- 本项目要求「随文出注」并配三家注（裴骃《集解》、司马贞《索隐》、张守节《正义》），白话本无法提供该层信息。

## 六、体裁与篇目边界

- 抓取本**只覆盖本纪、世家、列传**，**十表、八书全部缺位**（共 18 篇），另有《太史公自序》一篇未抓取。
- 表、书类篇目原典以表格、历法、礼乐制度为主，网络白话本普遍不作翻译，这 19 篇只能走**纯自译**路线。

---

## 七、结论与处置

| 判定 | 说明 |
|---|---|
| 不可直接入库 | 存在 468 处衍文污染及错字、残缺、漏译，直接采信将把错误带入成品 |
| 可作参照 | 整体文意有参考价值，可用于译文打磨时比对；**成稿须逐句回到原典独立撰写** |
| 逐篇必须核验 | 67 篇未自译篇目，逐篇「对标原典核验 → 重译 → 互校 → 上库」，不可跳过 |

> 一句话：白话本是一份带伤的通俗读物，能帮我们快速抓大意、供比对，但**不能当数据用**；凡入库文字，必须一字一句回到原典。
