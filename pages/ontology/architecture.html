🧱 核心架构：四轴七层设计

一、四轴正交坐标系

四轴相互正交，任意历史实体、关系、实例都可在四轴中定位，避免分类冲突：

坐标轴轴名覆盖内容典型类
A1体裁分类轴正史/编年/纪事本末/方志/专史/史料集史书体裁、丛书、断代归属、版本目录
A2史实内容轴时间·地理·制度·社会·经济·文化历史事件、典章制度、社会结构、经济形态
A3人物主体轴帝王→官僚→士人→庶民；史家历史人物、历史学家、注家、学派传承人
A4时序缘起轴事件→变革→战争→运动→史料生成历史事件、史料编纂事件、因果链、沿革过程

二、七层抽象层次

元模型层
定义轴(Axis)、层(Layer)、类(OntologyClass)、数据属性(DatatypeProperty)、对象属性(ObjectProperty)、实例(Individual)等最基础元类，为整个本体提供统一建模元语。
史观本体层
唯物史观、循环史观、进步史观、年鉴学派长时段理论等最上层历史理论，是所有历史解释的顶层理论框架。
史学范畴层
阶级分析法、计量史学、史料考据法等史学方法，以及封建、郡县、宗法、士族、改土归流等核心历史概念。
学派体系层
年鉴学派、古史辨派、马克思主义史学派、计量史学派等史学流派，以及社会形态分期、断代王朝分期、全球史分期等历史分期体系。
文献载体层
史书→卷→篇→段→正文/注，包含纪传体(本纪/表/书/世家/列传)、编年体(年度条目)、纪事本末体(事目)等不同体裁的结构化文本单元。
人物传承层
帝王、官僚、士人、庶民等历史活动人物，以及史家、注家、师承关系、家族世系。
记忆书写外延层
史学史、历史记忆、神话传说化人物、文化遗产等外延内容，覆盖史料生成之后的传播、诠释与记忆建构过程。

三、核心类体系（TBox）

共包含7大根类、38个核心类：

  • L0元模型类：Entity / Axis / Layer / OntologyClass / DatatypeProperty / ObjectProperty / Individual（7类）
  • L1史观类：HistoricalTheory
  • L2范畴类：HistoriographyMethod / HistoricalConcept
  • L3学派类：School / HistoricalPeriodization
  • L4文献类：Text → Biography(纪传) / Chronicle(编年) / Treatise(典志) / EventNarrative(纪事本末) / Gazetteer(方志)，下含 Volume(卷) / Chapter(篇) / Section(段) / Commentary(注疏)
  • L5人物类：HistoricalFigure → Emperor(帝王) / Official(官僚) / Literatus(士人) / Commoner(庶民) / Historian(史家)
  • L6外延类：HistoricalMemory / MythicizedFigure / CulturalHeritage
