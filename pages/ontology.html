📐 本体总纲

中国历史本体论建设规范与整体架构

本历史本体论采用「单本史书本体 + 历史全景本体」双层架构，既尊重每一部史书自身的体例与结构，又通过跨文本整合形成统一的中国历史事实网络：

📖 单本史书本体（文本层）

以具体著作为中心，还原每部史书的原生体例（纪传体/编年体/纪事本末等）、篇目结构、注疏系统，解决「一本书里写了什么、怎么写的」问题。

🌐 历史全景本体（史实层）

以历史事实本身为中心，跨书整合所有正史、编年、纪事本末史料，完成人物去重、事件对齐、异文考异、制度沿革追踪，解决「历史真实是什么」的问题。

🧱 一、核心架构：四轴七层设计 →

本体论整体骨架，包含「体裁分类轴 / 史实内容轴 / 人物主体轴 / 时序缘起轴」四轴正交，以及「元模型层 / 史观本体层 / 史学范畴层 / 学派体系层 / 文献载体层 / 人物传承层 / 记忆书写外延层」七层结构，定义全部类、属性、关系谓词。

📚 二、单本史书本体构建方案 →

针对每一部史书的体例特点设计专属本体，包含纪传体（二十四史）、编年体（资治通鉴）、纪事本末体、典章制度体等不同体裁的差异化建模方案，以及注疏系统、版本目录、校勘记的纳入规范。

🌐 三、历史全景本体构建方案 →

跨文本贯通建模规范，包含人物异名去重、事件异文对齐、制度沿革链、地理古今对照、因果关系网络、史料溯源考异等核心机制，继承司马光「考异法」传统，保证所有史实均有原文出处支撑。

实体对齐 跨书互证 考异系统 因果链 沿革追踪
